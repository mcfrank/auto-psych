What the inner loop found on existing reference-game data

Before running new experiments, we asked whether coding agents that write memo models of reference-game choices can find models that predict people better than the standard RSA models, on conditions they never saw, and whether the same loop recovers a model we hid from it. Two overnight sweeps on Sherlock answer both.

Answers

The setup

Data. Forced-choice listener trials from five sources: the lab's pragmods experiments, Sikos et al. (2021), and Mayn & Demberg (2022, 2023, 2026). Within each paper, whole conditions are held out (a condition, or one display of a multi-trial experiment). The loop trains on 39,955 trials; the test set is 10,632 trials in 84 held-out conditions. Agents never see the test set, the split or its provenance.

Starting models. Five memo models: literal_listener, rsa_l1, rsa_l2, rsa_l1_salience and rsa_l1_shared_prior. On held-out conditions the best of them is rsa_l2, the reference for every comparison below.

The loop. Each round, six Gemini 3.8 Flash agents (opencode, sandboxed) each write one candidate model: a memo listener plus numpyro priors, checked with the same gates the harness uses. Three slots explore under rotating "lenses", two refine the current best model, one refines a model the agent picks. A candidate is admitted if it fits, converges and predicts differently from every admitted model. At the end of the run, models clearly behind the best (more than 2 clustered SE) are pruned, the live set is capped, and the best model is exported.

Scoring claim 1. The exported model's held-out log predictive density minus rsa_l2's, with the SE of the difference clustered by held-out condition.

Recovery. Choices are simulated for every training and test trial from a starting model fitted to the real training data (literal_listener or rsa_l1_salience). That model, and for salience its near-twin rsa_l1_shared_prior, are withheld from the starting set. The loop recovers it if its exported model predicts within 0.01 RMSE of the ground truth's choice probabilities on a pool of displays.

Two runs

Run 1 was the pilot. Two things in it changed the design before run 2: trial-level PSIS-LOO pruned the models that generalised best (in real_rep1 the exported model ranked 26th of 40 on held-out conditions), and an agent read the lab's pragmods RSA code from GitHub. Both changes, and the rest of run 2's settings, were fixed before run 2 started.

Claim 1: better than the starting models on held-out conditions

In run 2 all three real-data replicates exported a model that beats rsa_l2 on the held-out conditions, each by about 2 to 2.4 clustered SE. Run 1's two replicates split: one gained +83, the other exported a model that generalised worse than the seed.

What the exported models share. All three combine pragmatic reasoning (depth 2 to 5) with a prior over referents that favours objects that stand out in the display: a singleton feature, an isolated or surprising one, a colour that pops. Each replicate reached it by refining one lineage of mechanisms rather than jumping between families.

Where the gains are. Almost all of it is pragmods and Sikos 2021. On the three Mayn & Demberg datasets no exported model moves held-out lpd by more than 2.2 from rsa_l2. Most of the spread between replicates is one pragmods experiment, E6 (favorite vs least favorite: 2 held-out conditions, 276 trials). Without it the three exported models gain .

Stopping rule (decided). From now on a loop ends early once two rounds in a row leave its best model unchanged. A one-round rule would have hurt: it stops real_rep1 after round 1, when rsa_l2 was still the best model, and real_rep2 at +26.7 instead of +56.2. The two-round rule changes nothing in either run; it ends runs that have plateaued. The round limit stays as a ceiling.

What selection rewards

Run 2 selected, pruned and exported on grouped cross-validation over training conditions, the same unit the test holds out. The exported models ranked 2nd, 8th and 11th of about 58 on held-out conditions (run 1: 26th and 4th of 40), and the live sets kept 12 models instead of collapsing to 4 and 1.

Grouped CV and the held-out test still weigh different conditions. In all three replicates CV's lead over rsa_l2 is about +350 to +420 nats on Sikos 2021. It comes from about ten Sikos training conditions where every starting model predicts at chance and a singleton prior fixes them. The held-out Sikos conditions are mostly other display types (+15 to +22). This is not overfitting, since CV also holds out whole conditions; the random split put those display types in training. The pruned models that did best on held-out conditions in real_rep3 (+50) won on E6, which CV barely sees.

Recovery

All eight recovery cells recovered their ground truth, four in each run. Run 2 did it without any internet access. The best starting model left in each set is about 0.048 RMSE from the ground truth, five times the threshold, so no starting model would pass.

  • Run 2 came closer. Exported models are 0.0012 to 0.0053 from the ground truth (run 1: 0.0044 to 0.0093). In both salience cells the exported model is also the live model closest to the ground truth, which never happened in run 1.
  • The salience ground truth was found close to its own form. rsa_l1_salience is a depth-1 RSA listener whose prior over objects is a softmax of how many features each has and how often it was seen during familiarisation. Both run-2 salience cells exported a depth-1 listener with those two terms in its prior (one adds a cost for ambiguous words).
  • The literal ground truth was found as behavioural equivalents. The literal listener picks uniformly among the objects that fit the word. The loop exported a literal/pragmatic mixture and a non-recursive distinctiveness heuristic, both of which predict like it within half a percentage point per choice; 9 or 10 of each literal cell's 12 live models pass. The data cannot tell these apart, and the held-out test agrees (exported minus ground truth within its SE in every cell).
  • Recovery is fast. In run 2 the literal cells reach the ground truth's held-out level after round 1 and the salience cells after round 3 or 4; later rounds change held-out lpd by a few tenths of a nat.

Cost and operations

Run 2 cost $ over agent runs (run 1: $, ). Each cell had 4 CPUs on the lab's Sherlock node; the 8-round real cells took 9 to 12 hours and peaked at 22 to 26 GB of their 30.

  • Three recovery cells crashed just after midnight: concurrent fit processes collided on arviz's once-a-day cache file. They resumed the same morning from their last scored step (about $10–15 of agent work lost per cell). Fixed since: each fit process has its own cache.
  • The first submission went to run 1's sweep folder (three scripts still defaulted to it) and was cancelled before it started. Fixed since: the default lives in one place.
  • No agent called a web tool in run 2. The activity report now lists web tool calls separately from URLs that only appear in log text.
  • Memory for the next runs is raised to 36 GB per cell (five cells at once on the node).

Going into the live experiments

Decided

  • Selection on grouped CV over training conditions; no source-specific rule.
  • No internet for agents.
  • Stop after two rounds without a new best model; 36 GB per cell.
  • Claim 1 is reported on the split fixed before the runs, per source and per experiment.

Open

  • Seeds for the live runs (claim 2). Proposed: the 36 models live at the end of run 2's real cells, refitted on all existing data, duplicates removed, grouped by mechanism, the best of each group by grouped CV, plus rsa_l2 as the reference. A CV-only cap would keep almost only the singleton family, because CV is mostly Sikos.
  • Round ceiling. With the stopping rule in place, real cells could get 10–12 rounds; run 2's real cells were still finding gains at round 7.

Limitations to state. The held-out gains rest mostly on two sources and, between replicates, on one pragmods experiment; the SEs are clustered over 84 conditions; the Sikos display types are unevenly split; and the exported models are specialists (no model is best on every source).
