# The number game: problem definition

The domain of inquiry is how people generalise a concept from a few positive
examples. A participant sees a set of example numbers between 1 and 100 that
a hidden program produced and judges, for other numbers between 1 and 100,
whether the program would produce them too. We seek an explanatory theory of
which numbers people take to belong with a set.

## Stimulus design schema

- **Stimulus**: a (set, target) pair. The set is one to four distinct numbers
  between 1 and 100, from a fixed list of 255 sets; the target is a number
  between 1 and 100.
- **Response**: yes (the program would produce the target) or no.

The design stage selects, from all 25,500 (set, target) pairs, the pairs that
jointly carry the most information about which model is correct.
