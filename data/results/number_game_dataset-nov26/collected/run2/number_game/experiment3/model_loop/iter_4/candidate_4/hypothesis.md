Refinement of the incumbent `parity_doubt_three_example_memory` by one grafted component, taken from `exception_tolerant_parity_doubt` (originally `single_exception_tolerance`): people allow that one of the examples they are reasoning from may be an odd one out, so whenever they judge from three or more examples — all three of a three-example set, all four of a four-example set, or the three that remain in working memory after one of four has dropped out — a property held by every one of those examples but one is still entertained as a possible rule, at an inferred fraction of the weight it would carry if all of them shared it. Everything else is the incumbent unchanged (the three-example memory limit averaged over which example was lost, the salience-weighted share of the shared profile with the interval similarity, and parity-kept rule-ambiguity doubt at every set size), so on three- and four-example sets targets carrying an almost-shared property are endorsed more than the strictly shared profile implies. (The one significant critique, a lower yes rate early in the session, depends on trial position, which a stimulus-only model cannot represent.)
