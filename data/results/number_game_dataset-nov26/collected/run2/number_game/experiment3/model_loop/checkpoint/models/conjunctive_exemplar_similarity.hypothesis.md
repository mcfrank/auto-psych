People do not infer a rule; they keep each example shown as a stored exemplar and ask whether the target resembles every one of them at once (a conjunctive, product-rule exemplar comparison). Similarity to each stored example falls off exponentially with the salience-weighted fraction of that example's own properties (parity, primality, squares/cubes, powers, multiples, round multiples of 5/10, final digit, contained digits) that the target lacks plus their distance in magnitude, and the similarities to the examples are multiplied together, so a single badly mismatched example vetoes the target while a property carried by every example counts fully and one carried by only some counts in proportion.
