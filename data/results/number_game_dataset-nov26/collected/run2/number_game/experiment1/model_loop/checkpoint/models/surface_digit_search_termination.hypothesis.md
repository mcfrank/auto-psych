People search the examples for shared properties in order of how visible they are, beginning with the written surface of the numbers, and when that first glance turns up a shared final digit they largely stop searching: the deeper arithmetic properties the examples also happen to share (primes, squares/cubes, powers, multiples) are only partly noticed. They then say "yes" in proportion to the salience-weighted share of the noticed shared profile the target also has (with one-sided magnitude bounds and no size principle), so when a common last digit is present, a target that keeps that digit is endorsed strongly even if it breaks an incidental arithmetic pattern such as "multiple of 7".
