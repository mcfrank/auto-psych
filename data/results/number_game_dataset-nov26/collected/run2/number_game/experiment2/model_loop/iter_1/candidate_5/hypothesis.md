Refinement of `seed_multiple_digit_overshadowing` by one change: when the program has shown only a single example, people see no evidence that it is restricted to any particular pattern, so they lean toward "yes" for every target, by an inferred amount, on top of the usual judgment. Otherwise the judgment is unchanged: "yes" follows the salience-weighted share of the examples' shared property profile that the target has, a final digit visibly shared by several examples overshadows the other properties, and "multiples of the smallest example" joins the profile when it divides all the others. So non-example targets for one-example sets (e.g. 48 -> 18, 60, 72) are endorsed more than the same degree of profile match would earn after two or more examples. This addresses the critique that the best model under-generalizes from single examples.
