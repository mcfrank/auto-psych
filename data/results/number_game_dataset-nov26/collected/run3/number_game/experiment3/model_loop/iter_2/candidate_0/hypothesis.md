When people compare the examples, they notice the most specific property all of them share (for example, all ending in 3), and they treat broader properties that it implies (being odd, containing a 3) as by-products of it rather than as separate candidate rules. A broader rule is set aside more completely the more specific the shared property that implies it, while people otherwise infer the concept by tempered Bayesian concept learning over rules and magnitude ranges. So after sets like 63,23,43 or 93,43,83,53, same-parity numbers with a different final digit should be endorsed less than the current best model predicts, while a lone example, which allows no comparison, is unaffected.
