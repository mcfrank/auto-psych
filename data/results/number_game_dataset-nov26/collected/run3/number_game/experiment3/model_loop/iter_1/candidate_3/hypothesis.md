Refinement of `range_specific_evidence_strength`. It keeps the same tempered, sample-size-neglecting Bayesian concept learning over weighted rules, size-weighted ranges, their odd/even versions and bounded rules that every example fits, with comparison-based rules discounted for a lone example and ranges weighed with their own evidence strength. The one change: people look for a mathematical or digit rule first and fall back on a plain magnitude range when no rule fits every example, so ranges become more plausible a priori, by an inferred amount, exactly when no rule fits fully (no shift recovers the incumbent). For such sets belief should move from rules that one example breaks to ranges covering all the examples. In-range targets should then be endorsed more, and members of a partly shared rule less, while sets that a rule fits fully stay as they are.
