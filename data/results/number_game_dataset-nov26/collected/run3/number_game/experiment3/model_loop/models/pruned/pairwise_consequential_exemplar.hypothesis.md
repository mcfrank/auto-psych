People do not infer one concept that explains all the examples together; they store each example as a separate exemplar and judge the target by how similar it is to each stored example on its own, where two numbers are similar to the extent that familiar number concepts (mathematical and digit rules, magnitude ranges), weighted toward small concepts, would contain both (Shepard's consequential-region similarity). They say "yes" according to the target's average similarity to the stored examples, so a target strongly linked to only some examples (sharing a property with one, lying near another) still earns partial endorsement, and adding examples does not make generalization any tighter through a shared, suspiciously coincidental pattern.
