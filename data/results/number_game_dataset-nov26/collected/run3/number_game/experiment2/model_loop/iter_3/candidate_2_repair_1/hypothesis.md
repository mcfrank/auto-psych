People infer the program's concept by the same tempered Bayesian concept learning as the current best model (weighted mathematical/digit rules, size-weighted magnitude ranges, odd/even versions and range-bounded rules, with sample-size neglect and digit rules discounted after a lone example), but working memory is limited: on an inferred share of trials only the most recently shown example is still held in mind when the target is judged, so they generalize from that last example alone. This predicts that earlier examples are endorsed less than the last one, that after several examples people still partly generalize broadly from the final example (to its multiples, digits and neighbourhood), and that the same examples in a different order lead to different judgments.
