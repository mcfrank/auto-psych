Refinement of `comparison_dependent_concepts`. People learn the program's concept in the same way: tempered, sample-size-neglecting Bayesian concept learning over weighted rules, size-weighted ranges, odd/even versions and range-bounded rules, with comparison-dependent concepts discounted for a lone example. The one change is that examples do not all count equally as evidence. How much an example counts depends on where it appears in the list, so evidence is shifted smoothly toward the first examples (primacy: the opening examples anchor the guess and later ones revise it less) or toward the last ones (recency), by an inferred gradient, while the total evidence stays the same. This predicts that the same examples in a different order produce different generalization; in particular, an example that breaks the others' pattern weakens the tight concept more when it sits at the favoured end of the list.
