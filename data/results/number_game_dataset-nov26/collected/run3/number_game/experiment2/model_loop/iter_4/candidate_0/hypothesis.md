Refinement of `comparison_dependent_concepts`. The learner is the same: tempered, sample-size-neglecting Bayesian concept learning over weighted rules, size-weighted ranges, their odd/even versions and range-bounded rules, with lone-example discounts. The one change is that people apply the size principle only to rules, whose members they can list. For a magnitude range they only check whether it admits each example, and every admitted example counts as equally likely however wide the range is (as if drawn from a window of one inferred reference width), so how broad a range they favour comes from their prior alone. A range that covers all the examples then beats a small rule that must treat some examples as strays. For sets that no rule covers (71,61,26,81; 70,88,7,22), people should endorse targets inside the examples' span more, and targets outside it less, than the incumbent predicts.
