Refinement of `range_bounded_parity_concepts`: people do the same tempered-evidence Bayesian concept learning over the 45 weighted rules, all intervals, their odd-only and even-only versions and the range-bounded rules, but they do not count the examples as independent evidence. Each additional example is treated as partly redundant with the ones already seen, so the strength of the evidence grows sublinearly with the number of examples, at an inferred rate (no discount recovers the incumbent). This predicts that a single example already drives sharp rule-based generalization (10 → 60, 70, 80, 90; 11 → 22, 55, 99), which addresses the critique that people generalize more broadly from one example than the model allows, while three or four examples tighten generalization less than independent sampling implies.
