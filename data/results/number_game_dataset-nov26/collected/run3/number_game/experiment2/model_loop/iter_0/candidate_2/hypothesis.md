People revise a running guess about the concept as each example arrives, and how much an example sharpens that guess grows with its serial position: the first example only seeds a broad set of candidate concepts and counts as weak evidence, while each later example, arriving once a guess is already forming, is weighed more heavily as confirmation (the same rule, range and odd/even concept space as the best model, with evidence weight rising as a power of the example's position). This predicts broad generalization from a single example, sharper generalization only as more examples accumulate, and that the same examples shown in a different order lead to different generalization because the later ones dominate.
