People judge a target by its similarity to the examples, where two numbers are similar to the extent that they share number properties (parity, primality, being a square/cube/power, divisibility, final digit, digits contained, and a magnitude band of width 20), each shared property counting by how rare, and so informative, it is. The criterion is relative: people say "yes" when the target is about as similar to the examples, on average, as the examples are to one another, so a set whose members are loosely related (no common rule) accepts loosely related targets such as nearby numbers, while a tightly related set (all ending in 2) demands the same tight relation. A lone example, which has no partner to compare with, is judged against a fixed default criterion.
