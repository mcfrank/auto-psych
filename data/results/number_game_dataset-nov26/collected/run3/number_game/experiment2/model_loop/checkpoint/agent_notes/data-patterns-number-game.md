Observed in cell_1 responses.csv (2520 rows, 9 responses per (set,target) cell, no participant_id):
- Sets whose examples all share a last digit (72,92,82,42; 63,23,43; 59,89,79; 93,43,83,53) get very low yes for other-digit targets (~0.05), even inside the example range; 28,98 gives ends-in-8 targets ~0.77.
- Arithmetic rules get weak contrast: 100,1,16 squares are not endorsed above non-squares; 69,9,39,21 non-multiples of 3 ending in 9 are rated high.
- Parity conjunctions show up: 63,27,99,33 odd multiples of 3 >> even ones; 84,56 odd multiples of 7 rated low.
- Earlier rounds' significant results: iter_0 min-rule member rate, shared-last-digit nonmember; iter_1 outside-minus-inside range (people stay inside the range more), fewer intermediate cells.
**Why:** saves re-deriving these each critique round. **How to apply:** aim new statistics at patterns that haven't been tested yet; check ppc_results in iter_*/critique.
- iter_2 cand_1 (attention_weighted_generalization_gradient): exp gradient with attention = idf * share^gamma on examples' consistent features + magnitude-outside-range dim; smoke-fit in-sample loglik -1554 (vs incumbent ELPD -1600) — unnormalized consistency-weighted similarity is far better than averaged-feature similarity models (~-1665).

Incumbent's biggest residuals: even targets for all-odd sets (63,27,99,33→42; 23,35,95,83→34) predicted ~0.33, observed 0; 98,83→8/28 overpredicted. Parity restriction helps only modestly.
