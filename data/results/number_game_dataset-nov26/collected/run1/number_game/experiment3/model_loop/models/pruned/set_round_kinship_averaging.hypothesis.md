Refinement of the incumbent `round_number_averaging_exemplar` (averaged similarity on magnitude, final digit, parity and the set's common divisor, sharpened by suspicious coincidences, plus distance-free multiples, factor-kin and round-number routes). The one change: round-number kinship is read from the set as a whole, not from any single example — a round target gains distance-free support from 0/5-ending examples only to the extent that the set as a whole looks round, so the route weakens steeply with the fraction of examples that do not end in 0 or 5. Lone round-ish examples and all-round sets ("5", "45, 90") still carry round targets (100, 50), but a single 5-ending example inside a mixed set ("15, 11", "6, 25") gives round targets like 40 or 80 almost no boost.
