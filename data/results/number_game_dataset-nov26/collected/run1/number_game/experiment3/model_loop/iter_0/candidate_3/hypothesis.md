Refinement of the incumbent `round_number_averaging_exemplar`. Support is still pooled by partly averaging similarity to the examples (magnitude, final digit, parity, the set's common divisor, sharpened by suspicious coincidences), with distance-free routes for multiples and factor-kin. The one change is that people read round-number kinship from the set as a whole, not from any single example: a multiple-of-ten target gets the distance-free round boost only in proportion to how round the whole set looks (the share of its examples ending in 0 or 5, with how steeply this matters inferred from the data). So round sets ("45, 90", "5", "80, 70, 90, 100") still carry far round targets, but a single 5-ending example in a mixed set ("15, 11", "6, 25") lends 30, 60 or 100 almost no support.
