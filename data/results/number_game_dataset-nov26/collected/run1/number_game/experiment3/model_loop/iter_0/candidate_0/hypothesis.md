People judge each target by its similarity to the examples exactly as in the current best account, but the criterion they hold for saying "yes" is not fixed: it relaxes (or tightens) steadily over the course of the session, so the same set and target is endorsed more readily late in the session than early on. This is a decision-level shift in response bias over time, not a change in how the examples are generalized, and the direction and size of the drift are inferred from the data.
