Refinement of `recency_gated_arithmetic_route` (rank 1, tied with the best), with one component grafted from `similarity_averaging_exemplar`. People judge a target by its similarity to each example: magnitude, final digit, parity and the set's common divisor, all sharpened by suspicious coincidences. They also use distance-free arithmetic routes (multiples, factor-kin and round-number kinship), which need the example held in working memory and so fade with each later example. The one change is that people pool this support across examples by partly averaging it rather than summing it, so each further example dilutes a target's support. Near and far targets in 3-4-example sets therefore get less support than in single-example sets. A round target in a mixed set like "15, 11" is weakly carried, because the lone 5-ending example is both diluted and faded.
