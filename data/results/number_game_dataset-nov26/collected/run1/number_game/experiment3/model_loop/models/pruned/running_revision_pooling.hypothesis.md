People read the examples one at a time and keep a running impression of what the program produces, revising it with each new example by an amount that shrinks with how many examples they have already seen (at a rate inferred from the data). A target is then judged by its similarity to that running impression (magnitude, final digit, parity, the set's common divisor, plus the distance-free multiples, factor-kin and round-number routes, with suspicious coincidences making the decision more decisive), so the examples count unequally by serial position: if the revisions are large, the last example shown dominates (21 after "9, 3, 7" counts more via the 7 than 18 via the 9); if small, the first impression sticks; equal weighting is the special case of the current best model.
