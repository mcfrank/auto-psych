People infer the hidden program as a Bayesian concept learner would: they weigh candidate rules (odd/even, primes, squares, cubes, powers, multiples of a number, a shared final digit) and magnitude ranges by how well each explains the examples, favouring small concepts that would make the examples a suspicious coincidence (the size principle), and say yes according to how probable it is that the target belongs. The one distortion is sample-size neglect: people treat a set of several examples as only a little more informative than a single one, so the total evidence grows much more slowly with the number of examples than the size principle says. Four examples therefore narrow generalization far less than normative inference implies (e.g. "63, 27, 99, 33" still admits broad ranges and loose rules), while single-example generalization is unchanged.
