Refinement of `variability_tuned_exemplar_attention`: people still judge a target by its summed similarity to the remembered examples, with attention to magnitude and final digit set by how variable the examples are on each. The one change is that the same variability-driven attention also reaches parity (odd/even): the more the examples agree in parity (e.g. all even), the more a parity mismatch with an example lowers similarity, so after same-parity sets, same-parity targets far from every example and sharing no final digit are still endorsed more than opposite-parity ones, while mixed-parity sets ignore parity.
