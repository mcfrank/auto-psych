Refinement of `graded_parity_variability_exemplar`: people still judge a target by its summed similarity to the remembered examples, with magnitude and final-digit attention tuned to how variable the examples are and a fixed parity penalty. The one change is that the response criterion is not shared across sets: on reading each example set, people adopt their own threshold for how much similarity is enough to say "yes" (some sets suggest a broad, permissive category, others a strict one), drawn from a population distribution whose spread is inferred. This predicts that sets differ in overall willingness to say yes more than similarity alone produces, while the ordering of targets within a set is still set by similarity.
