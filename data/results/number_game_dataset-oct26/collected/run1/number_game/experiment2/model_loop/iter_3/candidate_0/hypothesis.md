People judge the target as the current best model says (final-digit similarity to the examples with parity credit suppressed when the examples share one final digit, a boost for multiples of the examples' common factor, and familiarity with the band of decades the examples span), but how much weight they put on that magnitude (decade) familiarity depends on how many examples they saw: with a lone example there is no relational structure to extract, so people lean heavily on "numbers near that one" and readily accept other numbers in its decade, while each additional example supplies digit and arithmetic structure that draws attention away from magnitude, so the decade-familiarity boost is diluted as the number of examples grows. This addresses the critique that, after a single example, people accept same-decade targets with a different final digit far more than the model predicts.
