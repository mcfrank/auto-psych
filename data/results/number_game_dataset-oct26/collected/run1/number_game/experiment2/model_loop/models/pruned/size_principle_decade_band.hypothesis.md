People generalize as a Bayesian learner would from the band of decades the examples span (with final-digit similarity, parity credit suppressed by a shared final digit, and a common-factor boost as in the current best model), applying the size principle to that magnitude concept: the narrower the band of decades the examples occupy, the more strongly a target inside it is judged likely, so a single example or a set confined to one decade produces strong within-decade generalization while a band covering many decades confers little. The one distortion is that the size principle is applied with an inferred, partial strength rather than in full, so familiarity falls with the band's width by a weaker-than-normative power.
