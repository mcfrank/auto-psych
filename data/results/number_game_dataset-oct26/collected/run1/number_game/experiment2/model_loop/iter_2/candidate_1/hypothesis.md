People treat each example as a separate piece of evidence about the program and accumulate that evidence across examples, rather than merely averaging their resemblance to them: every example whose final digit the target fails to share costs some credibility (a little for a same-parity mismatch, more for an opposite-parity one), and these costs pile up with the number of examples shown (with an inferred degree of accumulation between pure averaging and full summing), so judgments sharpen as more examples agree. Thus a target that breaks a final digit shared by three examples (e.g. 69 after 59, 89, 79) is rejected more firmly than one breaking a single example's digit, while decade-band familiarity and membership in the examples' common-factor multiples still shift the answer as in the incumbent.
