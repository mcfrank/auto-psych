People do not infer a rule; they abstract a prototype of the examples as a profile of how often each number feature occurs among them (each final digit, odd/even, each decade, and divisibility by 3, 4 and 5), blending these observed frequencies with a weak prior expectation that any feature value is possible, and they say "yes" according to how typical the target is under that profile. Because the prior expectation is diluted as examples accumulate, a feature value seen in every example becomes more and more expected (and an unseen one more and more atypical) with each further consistent example, so generalization sharpens with set size without any rule or size principle being computed.
