People bring stable, set-independent preferences for particular numbers to the task: some numbers (familiar, "lucky" or culturally salient ones) simply feel more like something a program would produce, and others less, so each number 1-100 carries its own intrinsic plausibility that shifts "yes" toward or away from it by the same amount whatever examples are shown. How strongly these number-specific preferences vary is inferred, with each number's own shift learned from all the sets it is asked about; apart from this, judgments follow the current best model (final-digit similarity judged by its shortfall from the examples' mutual similarity, rule-pre-empted parity credit, round and non-round common-factor rules, rule-gated decade-band familiarity, step-costed counting up from single examples, and the size principle on a shared final digit).
