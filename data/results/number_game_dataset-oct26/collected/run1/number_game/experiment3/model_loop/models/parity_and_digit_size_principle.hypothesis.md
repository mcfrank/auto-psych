A refinement of the incumbent `digit_rule_size_principle_counting` (final-digit similarity judged by its shortfall from the examples' mutual similarity, rule-pre-empted parity credit, a privileged round common-factor rule, rule-gated decade-band familiarity, step-costed counting up from single examples and the size principle on a shared final digit, all kept). The one change extends the size principle to parity: when every example is even (or every example is odd), each example beyond the first is another suspicious coincidence that firms up an "even numbers" (or "odd numbers") rule, so a target of the opposite parity is rejected by an inferred, additional amount per confirming example — e.g. 37 is rejected more after 4, 16, 12, 64 than after 4, 16 — whereas the incumbent's mutual-similarity shortfall is the same for two or four same-parity examples.
