A refinement of `digit_similarity_with_range_extension`: people still say "yes" in proportion to the target's average final-digit similarity to the examples (same digit most similar, same parity partly, opposite parity least), but the one change is how magnitude enters — instead of a separate, digit-independent boost for lying inside the examples' span, each example's final-digit resemblance counts for more the closer that example is numerically to the target (its weight fading smoothly with distance down to an inferred floor). So a digit match with a nearby example drives "yes" far more than the same match with a distant one, which addresses the critique that numerical proximity boosts digit-matched targets.
