A refinement of `exemplar_feature_similarity_gcm`. It keeps the same exemplar representation: magnitude plus arithmetic features, with similarity falling off exponentially with attention-weighted distance. The one change is that people judge the target by its similarity to the single most similar example shown (nearest-neighbour retrieval), not by its similarity summed over all the examples. So adding examples does not inflate "yes" for every target. A lone example generalizes as broadly as a rich set, and a target that closely matches any one example on its arithmetic features is accepted however far it is from the others. This addresses the critique's finding that the summed model under-generalizes from single examples and from numerically distant targets.
