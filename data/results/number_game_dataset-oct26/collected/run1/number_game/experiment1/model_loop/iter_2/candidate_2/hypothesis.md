People judge by the same simple rule matching as the best current model (saying yes to the degree that the target has the arithmetic properties all the examples share), but the decision rule differs: on seeing each example set, a person settles on a response criterion for that set, a set-specific bias toward answering yes or no, which varies from set to set by an inferred amount and is then applied to every target asked about with that set. So sets differ in overall generalization breadth well beyond what their shared properties explain, while the rank order of targets within a set still follows rule matching.
