A refinement of `shared_property_rule_matching`: people still say "yes" to the degree that the target has the arithmetic properties all the examples share, but they also treat the span of the examples (from smallest to largest) as part of what the program produces, so a target inside that span gets an extra, inferred boost to "yes" that fades smoothly with how far the target lies beyond the span's edges (for a single example, with its distance from that example). The one change is this range-membership component grafted from `range_extension_by_spacing`, which addresses the critique that the rule model misses interval-based generalization: in-range rule violators and in-range targets of rule-less sets are accepted more than distant ones.
