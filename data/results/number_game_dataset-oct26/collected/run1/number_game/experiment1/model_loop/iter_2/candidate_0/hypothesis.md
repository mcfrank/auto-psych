People build their guess about the program's rule incrementally, in the order the examples are shown: the first example suggests a set of arithmetic properties (parity, divisibility by 3/4/5/10, final digit, prime, square, power of 2), and each later example revises the strength of belief in each property by an error-correcting (delta-rule) update at an inferred learning rate, so that a slow learner stays anchored on the first example (primacy) and a fast learner is dominated by the last one (recency). They then say "yes" to the degree that the target has the properties their final, order-dependent guess favours, regardless of its magnitude.
