People represent each number by its decimal place values — a tens digit and a units digit — and judge the target by its digit-wise similarity to each example: similarity is the product of how alike the units digits are (identical most, same parity partly, opposite parity least) and how alike the tens digits are (falling off with the number of decades between them). They say "yes" in proportion to the target's average place-value similarity to the examples, so a target sharing an example's final digit is accepted strongly when it is in the same or a neighbouring decade but much less when it lies many decades away.
