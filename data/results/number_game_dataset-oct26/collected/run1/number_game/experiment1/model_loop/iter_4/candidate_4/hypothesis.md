A refinement of `final_digit_similarity_gradient`: people still say "yes" in proportion to the target's average final-digit similarity to the examples (same digit most similar, same parity partly, opposite parity least), but the one change is that each example's digit resemblance is weighted by how numerically close that example is to the target, so a shared ending counts fully when the matching example is nearby and only partly (down to an inferred floor) when it is far away. This makes magnitude modulate digit similarity example by example rather than adding a separate range bonus, addressing the critique that digit-matched targets near an example are accepted more than digit-matched targets far from every example.
