Refinement of graded_factor_coherence_tuned_exemplar: people still judge a target by its recency-weighted exponential similarity to the remembered examples (size, final digit, parity, graded shared factor), with attention stretched toward the respects in which the examples resemble one another, but how readily a shared property captures attention differs by kind of property. The single change is that each dimension gets its own coherence sensitivity instead of one shared stretch factor, so a set whose examples all end in the same digit (or share a large factor) can make people generalize an "ends in d" (or "multiples of g") rule far more sharply than coherence in size or parity does, closing the shared-final-digit and common-factor rule gaps in the critique.
