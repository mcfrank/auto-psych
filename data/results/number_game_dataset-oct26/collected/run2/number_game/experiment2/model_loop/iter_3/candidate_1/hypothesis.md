The single change is a memory process in how the filled-in size span is held: people anchor the span on the most recently shown example, and the positions of earlier examples fade in memory, so the stretch each earlier example adds to the span shrinks back toward the last example the further back it was shown. Targets lying on the last example's side of the set are therefore treated as inside the span (and endorsed) more often than equally placed targets on the first example's side, the recency bias in size generalization that the critique reports.
