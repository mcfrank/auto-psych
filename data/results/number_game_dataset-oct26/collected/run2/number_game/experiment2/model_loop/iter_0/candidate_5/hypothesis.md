Refinement of coherence_sharpened_decision_exemplar: people still judge a target by its recency-weighted exponential similarity to the remembered examples (size, final digit, parity, graded shared factor), with attention stretched toward the respects in which the examples resemble one another and set coherence sharpening how decisively similarity is turned into an answer.
