People do not compare the target with each example separately; they judge its similarity to the region of number space the examples jointly occupy. Distance to that region is the sum of how far the target lies outside the examples' size range (measured relative to how widely the examples are spread, so tightly clustered examples give a steep gradient and widely spread ones a shallow one) plus a mismatch on each property for which the target takes a value none of the examples has (final digit, parity) or lacks the factor all the examples share, and the probability of "yes" falls off exponentially with that distance.
