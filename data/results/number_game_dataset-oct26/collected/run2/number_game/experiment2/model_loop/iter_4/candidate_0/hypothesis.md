People estimate how variable the program's output is from how spread out the examples are, and generalize in size accordingly: they judge a target by its recency-weighted similarity to the remembered examples (size, final digit, parity, shared factor), but the size gradient around every example is stretched in proportion to the spread of the examples. A tightly clustered set (66, 78) is generalized narrowly in size and a widely spread set (10, 50, 100) very broadly, both inside and beyond its range, so whole sets differ sharply in how generously they are generalized.
