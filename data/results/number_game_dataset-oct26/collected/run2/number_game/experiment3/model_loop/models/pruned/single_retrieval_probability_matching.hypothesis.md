People decide by probability matching on a single retrieved memory rather than by thresholding summed familiarity: on each question they recall one of the examples (the more recently shown, the likelier it comes to mind), accept the target with a probability equal to how similar it is to that one example (in size, final digit, parity and shared factor), and if that recalled example does not vouch for the target they fall back on a fixed guessing rate of "yes". The yes-rate therefore rises linearly with similarity, from a guessing floor to a ceiling below certainty, with no sigmoid sharpening of the evidence.
