People cannot hold every example in working memory while judging the target: each example shown is retained independently with an inferred probability, and they infer the program's concept only from the examples they happen to retain, using the same conservative Bayesian concept learning as the best model (arithmetic rules and decade-favoured number ranges, evidence weight growing with the number of examples held, an inferred tolerance for stray examples, guessing that becomes rarer as more examples are shown). Because the answer averages over which examples were kept, a forgotten example neither rules out concepts nor tightens them, so larger sets generalize more broadly and more gradedly than full use of the evidence allows — e.g. a target fitting most but not all examples, or near only some of them, still earns partial "yes" — regardless of the order the examples were shown.
