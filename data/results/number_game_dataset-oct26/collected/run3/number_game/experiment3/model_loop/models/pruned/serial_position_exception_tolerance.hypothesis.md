People learn the program's concept by conservative Bayesian concept learning over arithmetic rules and number ranges (the size principle, evidence weight growing with set size, guessing that becomes rarer as more examples are shown), but they read the examples in order, and how readily they dismiss an example as a stray number outside the program's rule depends on where it came in the sequence: examples at one end of the sequence (earlier or later — the direction of this serial-position gradient is inferred) are more easily written off as exceptions than the others. This predicts that a set whose odd-one-out comes at the suspect end keeps the rule the other examples share (endorsing far targets that fit it), whereas the same odd-one-out at the trusted end forces people toward a range spanning all the examples.
