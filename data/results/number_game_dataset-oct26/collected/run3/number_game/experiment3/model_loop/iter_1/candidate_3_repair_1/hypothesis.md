Refinement of `outlier_tolerant_rule_concepts`: people do the same conservative Bayesian concept learning over the 42 arithmetic rules and midpoint-weighted number ranges (evidence weight growing with set size, an inferred tolerance for stray examples, guessing that becomes rarer as more examples are shown), but they anchor each edge of a range on the decade grid separately: a range is a priori more plausible for every edge that falls on a decade boundary ("from 23 up to the end of the 20s", "from 20 up to 25"), rather than only when both edges do. The one change is this edge-by-edge decade preference, which predicts that a target just outside the examples' span is endorsed more when it lies in the same decade as an example (29 or 21 after 23, 25) than an equally near target across a decade boundary (31 or 19) — the same-decade generalization the incumbent's critique flags.
