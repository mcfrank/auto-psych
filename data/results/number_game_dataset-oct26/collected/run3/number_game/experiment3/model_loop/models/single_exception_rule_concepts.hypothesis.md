Refinement of `outlier_tolerant_rule_concepts`: people do the same conservative Bayesian concept learning over the 42 arithmetic rules and midpoint-weighted, decade-favoured intervals of 1-100 (evidence weight growing with set size, an inferred tolerance for a stray example, guessing that becomes rarer as more examples are shown), but they allow the program at most one exception per set: either every example came from the concept, or exactly one of them is a stray number, never two or more. The one change is this single-exception limit (replacing independent strays for each example), which stops a patternless set of three or four examples from being explained as a tight cluster plus several strays, so people credit a range spanning (nearly) all the examples and fill its gaps with "yes" — the excess in-range "yes" for patternless sets the incumbent's critique flags.
