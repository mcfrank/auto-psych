Refinement of `outlier_tolerant_rule_concepts`: people do the same conservative Bayesian concept learning over the 42 arithmetic rules and midpoint-weighted, decade-favoured number ranges (an inferred tolerance for stray examples, guessing that becomes rarer as more examples are shown), but how the weight they give the examples' evidence changes with the number of examples differs between the two kinds of concept: each further example that fits a tight arithmetic rule keeps counting as a suspicious coincidence, whereas the evidence that examples cluster within a narrow range is discounted as examples pile up, each at its own inferred rate (the incumbent uses one shared rate). The one change is this concept-family-specific growth of evidence weight with set size, which predicts that after several examples that all fit a small rule (e.g. 80, 70, 90, 100 or 10, 50, 100) people commit to that rule over broader rules and ranges that also contain them, and so reject non-round targets (75, 85, 23) more sharply than the incumbent — the excess non-round "yes" for all-round sets its critique flags — while patternless sets still generalise broadly across the examples' span.
