People learn the program's concept by the same conservative Bayesian concept learning as the best model (arithmetic rules and midpoint-weighted, decade-favoured number ranges, evidence weight growing with set size, an inferred tolerance for stray examples, guessing that becomes rarer as examples accumulate), except that "prime numbers" is not a concept they spontaneously consider: primality is not perceptually or computationally available when glancing at numbers, so a set of primes is read as odd numbers or as a range. This predicts that after a set of primes, far odd non-primes (e.g. 81, 9) are endorsed as often as far primes, and far primes are endorsed less than a prime-aware learner predicts.
