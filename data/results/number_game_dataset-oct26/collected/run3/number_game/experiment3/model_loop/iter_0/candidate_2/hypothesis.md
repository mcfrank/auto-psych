People do not infer one concept that explains all the examples together; they store each example separately and judge the target by its average similarity to the stored examples (exemplar generalization), where the similarity of the target to a single example is how readily that one number alone would generalize to the target — shared membership in familiar arithmetic categories and number ranges, with small, specific shared categories counting more than broad ones. Because each example is compared on its own, a target similar to just one example of a mixed set (e.g. 27 in 92, 82, 27, 42) earns partial "yes", and adding consistent examples does not sharpen generalization beyond what each example licenses alone.
