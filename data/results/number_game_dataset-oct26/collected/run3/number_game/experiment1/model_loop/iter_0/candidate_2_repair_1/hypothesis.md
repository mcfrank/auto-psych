People learn the hidden program's concept by Bayesian inference with the size principle, but besides named arithmetic rules and numeric ranges they also consider any regular spacing the examples suggest: "every d-th number starting from r" for any step d (e.g. 3, 7 suggests 3, 7, 11, 15, ...; 20, 32, 92 suggests every 12th number from 8), with shorter steps more plausible a priori. Targets that continue the examples' common spacing therefore get "yes" even when no named rule (multiple of k, ending digit) covers them.
