People do not keep a full belief over every concept; they read the examples one at a time while holding a single working guess (win-stay, lose-sample). After the first example they pick a concept in proportion to how well it explains that example; each later example that the guess contains leaves it in place, and only an example it fails to contain makes them drop it and draw a new guess from what all the examples seen so far support. They answer "yes" if their current guess contains the target (apart from occasional blind guesses), so consistent later examples do not narrow the guess the way an ideal learner's belief narrows, and the order of the examples changes which concept people end up holding.
