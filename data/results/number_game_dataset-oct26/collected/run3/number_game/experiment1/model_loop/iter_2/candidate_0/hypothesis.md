People learn the program's concept by conservative Bayesian concept learning over arithmetic rules and numeric intervals (size principle), but they reason only from the examples they still hold in memory when the target is asked: the last example shown is always remembered, while earlier examples drop out of memory with a probability that grows the further back in the sequence they were shown. A forgotten example neither rules out concepts nor sharpens them, so generalization is driven mostly by the most recent examples, and reordering the same examples changes which targets get a "yes" (targets that fit only the first example are endorsed less often than ones fitting only the last).
