People do not infer a concept; they judge the target by its similarity to the stored examples (exemplar generalization), but their attention is drawn to the dimensions on which the stored examples cohere: every property all the examples share (parity, final digit, decade, contained digit, prime, square, cube, power-of-k, multiple-of-k) gets attention in proportion to how distinctive it is in 1-100, so a target that lacks a rare shared property (e.g. "ends in 8", "in the 20s") is judged dissimilar to every example, while closeness on the number line counts on a scale that stretches with the examples' spread. Saying "yes" is a Luce choice between the target's mean similarity to the examples and a fixed criterion.
