People learn the hidden program's concept by Bayesian inference over arithmetic rules and numeric intervals (size principle), but they do not weigh the examples equally: how strongly each example counts as evidence depends on its serial position in the order shown, with later (recency) or earlier (primacy) examples dominating the inferred concept. The total evidence is fixed by the number of examples and only its distribution across positions changes, so a single example gives ordinary concept learning, while reordering the same examples changes which targets get a "yes".
