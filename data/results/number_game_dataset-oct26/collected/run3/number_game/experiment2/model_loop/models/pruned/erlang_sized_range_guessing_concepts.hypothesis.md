Refinement of `evidence_scarce_guessing_concepts`: people do the same conservative Bayesian concept learning over the 42 arithmetic rules and midpoint-weighted, decade-favoured intervals of 1-100 (evidence weight growing with set size, guessing that becomes rarer as more examples are shown), but they also hold a prior preference for number ranges of intermediate width — Tenenbaum's Erlang size prior, with an inferred preferred scale, grafted from `iter1_candidate4` — so tiny near-singleton ranges and huge near-everything ranges are both a priori implausible. The one change is this interval size prior, which predicts that a lone example or a tight cluster generalizes to a moderately wide neighbourhood (e.g. "yes" to 50-60 after 55) rather than to the narrowest consistent range, while widely spread examples are no longer credited to ranges spanning almost all of 1-100.
