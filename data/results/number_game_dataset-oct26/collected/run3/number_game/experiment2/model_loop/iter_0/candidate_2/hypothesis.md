People revise their concept one example at a time, and the first example is read mainly as "the program can produce this number": it rules out concepts that do not contain it but only partly favours small concepts, because a lone number is no suspicious coincidence yet; every later example is treated as a deliberate sample, so the full size principle favours the tightest concepts that keep fitting (otherwise the same conservative Bayesian learner over arithmetic rules and decade-favoured ranges, with session-growing blind "yes"). Because which example comes first gets the weakened size principle, the order of examples matters, and a single example is generalized broadly to the large rules and ranges that contain it (e.g. 5 to other numbers ending in 5) while still sharply rejecting numbers that share nothing with it.
