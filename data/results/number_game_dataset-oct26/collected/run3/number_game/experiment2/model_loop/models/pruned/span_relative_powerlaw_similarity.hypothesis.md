People judge a target purely by its closeness on the number line to the span the examples cover: any target inside that span is judged fully similar, and a target outside it loses similarity by a power law in its distance beyond the nearest edge measured relative to the span's own width (plus an inferred baseline width, so a lone example still generalizes to its neighbours). The falloff grows steeper with every additional example, so a few spread-out examples license wide generalization while many tightly clustered ones license almost none; apart from occasional blind guesses, "yes" follows this relative-distance similarity.
