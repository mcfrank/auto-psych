I chose the incumbent, without_replacement_example_sampling, and refined how it believes random examples arise: people do the same Bayesian concept learning (45 independently weighted rules, ranges of 1-100 with a preferred typical width, in-concept examples drawn without replacement), but they think of a stray example as an occasional slip of the program per set of examples, not as an independent per-example coin flip — the chance that a set contains one, two or more random numbers falls off geometrically with their count (rate inferred) and does not grow with how many examples were shown, and any given count of strays is equally likely to be any of the examples. This predicts that with one or two examples a concept excluding an example is kept about as readily as with four, so the odd example out of a long, otherwise regular set (such as 25 in 91, 25, 61, 31) is judged a stray less readily than independent per-example noise implies, while short sets are discounted more readily.
