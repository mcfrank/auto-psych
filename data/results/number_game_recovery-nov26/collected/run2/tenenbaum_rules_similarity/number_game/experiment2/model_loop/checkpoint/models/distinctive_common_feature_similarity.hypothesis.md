People judge the target by its similarity to the example set as a whole, using a feature-based (Tversky-style common-features) metric: each arithmetic or digit property the target shares with the examples (parity, multiples, powers, squares, final digit, contained digit, and so on) adds to similarity in proportion to how consistently the examples share it and how distinctive (rare among 1-100) the property is, and closeness on the number line to the span of the examples adds a magnitude-band match that decays with distance. The probability of "yes" rises smoothly with this summed similarity; there is no inference over which single concept produced the examples, so a target that shares a distinctive property with most but not all examples still gets substantial "yes".
