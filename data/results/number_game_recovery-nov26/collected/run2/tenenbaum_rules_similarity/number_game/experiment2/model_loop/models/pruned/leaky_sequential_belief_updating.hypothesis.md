People revise a single running belief about the concept as they read the examples one at a time, but the belief is leaky: before taking in each new example they partly let go of what they believed so far, so their prior preferences and the evidence of earlier examples fade a little with every later example, while the latest example counts in full. This sequential, leaky updating predicts that with longer sets the prior plausibility of concepts matters less and the last examples dominate, so the same set shown in a different order generalises differently, and a concept that fits the final examples keeps weight even if it misses the first one.
