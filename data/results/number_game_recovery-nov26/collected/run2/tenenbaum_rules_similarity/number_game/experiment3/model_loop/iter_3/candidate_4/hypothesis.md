I refined the incumbent graded_ratio_ceiling_criterion. People do the same Bayesian concept learning (arithmetic and final-digit rules plus multiples of 13-50, rule runs confined to a stretch of the number line, ranges of a typical width, an inferred share of random examples, examples drawn without replacement, no "contains digit d" concepts) and treat the largest example as a soft ceiling whose extra demanded certainty grows with the ratio by which the target overshoots it. The one change is a set-novelty criterion: on the first question asked about a newly shown set of examples (or at the start of the session) people demand a different, inferred amount of certainty before saying "yes" (a single shift of the log-odds of their belief; zero recovers the incumbent), settling into their ordinary criterion once they have been asked about the same set again — so at equal belief, the first query about a new set gets fewer (or more) "yes" answers than the repeated ones.
