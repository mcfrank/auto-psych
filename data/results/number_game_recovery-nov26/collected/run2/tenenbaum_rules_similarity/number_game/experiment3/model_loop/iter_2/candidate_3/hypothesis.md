I refined the incumbent graded_ratio_ceiling_criterion. People do the same Bayesian concept learning (arithmetic and final-digit rules plus multiples of 13-50, rule runs confined to a stretch of the number line, ranges of a typical width, an inferred share of random examples, examples drawn without replacement, no "contains digit d" concepts) and treat the largest example as a soft ceiling whose extra demanded certainty grows with the ratio by which the target overshoots it. The one change is that this ceiling is inferred like an upper bound from samples ("German tank" reasoning): every example that fell at or below the largest one is further evidence that nothing much larger is produced, so the penalty for overshooting scales with the number of examples shown — a single example sets only a weak ceiling, while four examples all below 20 make 40 strongly implausible.
