A refinement of noisy_examples_erlang_intervals: people do the same Bayesian concept learning (45 independently weighted rules, all intervals of 1-100 with an Erlang prior favouring a typical range width, size principle, inferred rate of random examples), but on the first question after a new set of examples appears they are initially cautious and withhold some of the "yes" answers that inference supports, only fully committing to their generalisation once they have been asked about the same set again. The one change is this new-set caution: on the first query after a set change the probability of "yes" is the posterior probability that the concept contains the target scaled down by an inferred withholding fraction, while repeated queries about the same set follow the posterior unchanged.
