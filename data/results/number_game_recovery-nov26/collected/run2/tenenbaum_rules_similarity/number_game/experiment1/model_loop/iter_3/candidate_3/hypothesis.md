A refinement of noisy_examples_erlang_intervals: people do the same Bayesian concept learning over the 45 independently weighted rules and Erlang-size-weighted intervals of 1-100, with the size principle and an inferred example-noise rate, but on the first question asked right after a new set of examples appears they are cautious and, some inferred fraction of the time, answer "no" regardless of their posterior. The one change is this new-set caution, which predicts a lower yes-rate on the first query about a set than on later queries repeating the same set.
