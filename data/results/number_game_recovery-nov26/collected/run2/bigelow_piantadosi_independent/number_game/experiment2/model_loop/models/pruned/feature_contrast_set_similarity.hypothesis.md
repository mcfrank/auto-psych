People do not infer a hidden concept; they judge the target by its similarity to the example set on a feature-contrast metric: what counts is how many of the properties all the examples share (parity, primes, squares, powers, multiples, final or contained digit, weighted by how rare and thus distinctive each property is) the target also has, relative to the shared properties it lacks, together with how close the target lies to the nearest example on the number line (an exponentially falling gradient). The more similar the target is on this metric, the more likely people say yes, so a target that matches the examples' common distinctive properties is accepted even far from them, while a target that breaks them is accepted only if numerically very close to an example.
