People read the examples in the order shown and hold a single running guess about the program's concept (a mathematical rule or a numerical range), formed from the first example by the same capacity-limited Bayesian learning as the best model; each new example only revises that guess when it has to — a guess the new example fits is kept with a fitted probability (stickiness), and only otherwise is a new guess drawn from everything seen so far. Because guesses formed from early examples can outlive the evidence of later ones, the same examples shown in a different order are generalized differently, and broad concepts suggested by the first example survive longer than an order-blind learner allows.
