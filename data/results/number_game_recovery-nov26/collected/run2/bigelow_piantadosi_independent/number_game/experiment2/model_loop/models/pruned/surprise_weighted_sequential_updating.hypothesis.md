People read the examples one at a time, revising a running Bayesian guess about the concept (over mathematical rules, with separate prior plausibilities for even, odd and the other kinds of rule, and numerical ranges), and how much each new example counts depends on how surprising it is given the guess formed from the examples before it: an example the current guess predicted well is skimmed over, while an example that violates it (breaks the parity pattern, falls outside the range seen so far) captures attention and is weighted more heavily. Because the weight depends on the preceding examples, the same set shown in a different order is generalized differently, and pattern-breaking sets such as mixed-parity ones end up with their range taken more sharply than an order-blind learner would allow.
