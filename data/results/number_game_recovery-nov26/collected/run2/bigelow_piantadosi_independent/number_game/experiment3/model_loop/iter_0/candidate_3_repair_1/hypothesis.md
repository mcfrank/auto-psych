Refinement of `parity_veto_sparse_familiar_rules`: people infer the hidden concept by the same capacity-limited Bayesian learning over rules (with sparse rule familiarities) and numerical ranges, with the same parity-conflict veto at the decision, but they differ stably in how strongly they apply the size principle — how much they read the examples as deliberately sampled from a small concept. The single change is a personal sampling strength for each participant, drawn from a population spread and applied to every set that person sees, so some people narrow sharply onto the tightest rule or range covering the examples while others keep generalizing broadly; a new person is predicted by averaging over this population spread, which makes group-level generalization gradients flatter than any single typical learner's.
