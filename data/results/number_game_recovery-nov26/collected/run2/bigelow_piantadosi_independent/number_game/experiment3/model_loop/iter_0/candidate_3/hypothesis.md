Refinement of `parity_veto_sparse_familiar_rules`: people infer the hidden concept by the same capacity-limited Bayesian learning over rules (with sparse rule familiarities) and numerical ranges, and the same parity-conflict veto applies at the decision. The single change is that people differ stably in how readily they explain the examples by an arithmetic rule rather than by a stretch of the number line: each participant has a personal, consistent preference for rules over ranges, drawn from a population spread. So, for the same set and target, some participants keep endorsing distant rule members and rejecting in-span rule violators, while others answer mostly by numerical proximity, and each person does this across all the sets they see.
