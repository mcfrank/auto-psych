Screening refinements of `capacity_limited_evidence_integration` by MAP log-prob (find_MAP, ~1 min) before the 10-min check (2026-10-31, experiment2 iter_2 cand 3):
- Fuzzy target (blur membership over neighbours) and confusion with the nearest example: rho -> 0, no gain. The data reject proximity leaks, despite the similarity-leak critique.
- Log-odds response sharpening: no gain.
- Splitting "multiples of 5" into its own rule family: MAP logp -2119 -> -2071 (+48 nats, 1 param). The worst-fit set was 90,100,5 (people say yes to all multiples of 5); multiples of 7 were over-endorsed.
- (cand 2 repair) Decade rules ("the 80s") as a new family: -3 nats, no gain. Log-compressed sampling within ranges (p(x|range) ∝ 1/x): -30 nats, rejected. Multiples-of-m prior ∝ m^-k (fluency gradient): +13.7 nats, k≈1.55 -> submitted as multiplication_fluency_rule_prior. Existing MAP script: iter_2/candidate_3/scratch/map.py and diag.py.
- Noisy target magnitude (width -> 0) was rejected as a near-duplicate of the incumbent (RMSE 0.00085); any mechanism whose MAP pushes its parameter to the null will be rejected as a duplicate.

**Why:** a per-set deficit against a saturated per-cell model pinpoints the misfit far better than the critique statistics do.
**How to apply:** rank sets by that deficit first, then test changes by MAP before running the full check. Also, gradient cost must stay near ~45 ms or the fit exceeds 30 min.

Follow-up (2026-10-31, exp2 iter_2 cand 5 repair): one-change refinements screened on top of `base_ten_multiples_capacity_limited` (MAP logp -2071.0, ll -2039.0). None gives more than about 2.4 nats of log-lik:
- narrow-range prior width^-rho: ll +2.4, rho≈0.17 (submitted as narrow_range_base_ten_multiples; p_yes RMSE vs base_ten 0.012, so it passes novelty).
- parity-restricted ranges ("even numbers between a and b") as a new kind: ll +0.9. Separate range beta, or separate range gamma: ~0. Splitting squares from cubes: worse.
- A fuzzy-edge concept extension on narrow_range collapsed to strict membership and was rejected as a near-duplicate (RMSE 0.00095).
- Aggregate residual: in pure-parity sets, different-parity targets get fewer yeses than predicted; in mixed 4-example sets, in-range targets get more.
