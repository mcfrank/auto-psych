People read the examples in order and use the first one to call up candidate explanations (the arithmetic rules and the stretches of the number line that contain it), so the first example is partly spent on proposing candidates and counts less than later examples as evidence about whether a rule or a range is behind the program, although it still tells apart candidates of the same kind. As a result, the same examples shown in a different order are generalized differently: a set that opens with a number many rules contain (such as 64) is extended by rule less, and one that opens with a number few rules contain is extended by rule more, than an order-blind learner predicts.
