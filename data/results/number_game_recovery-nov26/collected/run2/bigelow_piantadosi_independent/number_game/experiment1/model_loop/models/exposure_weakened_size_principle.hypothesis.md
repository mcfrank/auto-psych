Refinement of `even_odd_split_family_prior`: people do the same Bayesian concept learning over the same 45 rules (separate prior plausibilities for even, odd and the other kinds of rule) and all intervals of 1-100 with a tempered size principle, but the strength with which they apply the size principle is not fixed — each further question about the same set of examples within a session weakens it (a fitted power-law decay with the number of earlier trials on that set), so the learner who is repeatedly probed about one set comes to treat its examples as less diagnostic of a small concept and generalizes more broadly. The single change is making the sampling strength depend on the set's exposure history, motivated by the critique that first encounters of a set are judged less generously than later ones, which an exposure-blind learner cannot produce.
