Refinement of `recency_weighted_even_odd_family_prior`: people do the same recency-weighted Bayesian concept learning over the same 45 rules (separate prior plausibilities for even, odd and the other kinds of rule) and all intervals of 1-100 with a tempered size principle, but the strength of the size principle is not fixed — it changes as a participant keeps judging targets for the same set of examples, so the "suspicious coincidence" that favours tight concepts fades (or hardens) with each repeated encounter of the set. The single change is making the sampling strength depend on how many times that participant has already seen the set (a fitted exposure gradient), motivated by the critique that first encounters of a set get fewer yeses than later ones, which predicts that generalization broadens toward wider ranges and broad rules on repeated exposures.
