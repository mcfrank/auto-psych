People infer the hidden concept by Bayesian learning over mathematical rules (with separate prior plausibilities for even, odd and the other kinds of rule) and numerical intervals, but how strictly they apply the size principle changes with exposure: the first time they are asked about a set they hold tightly to the smallest concept that covers the examples, and each further question about the same set makes them reconsider and loosen that strictness, so broader rules and wider ranges gain weight. This predicts that the same set and target earn more yeses the more times the participant has already been questioned about that set, with first encounters judged least generously.
