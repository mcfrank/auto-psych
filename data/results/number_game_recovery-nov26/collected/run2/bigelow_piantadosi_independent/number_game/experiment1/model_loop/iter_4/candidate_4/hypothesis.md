Refinement of `recency_weighted_even_odd_family_prior`: people do the same recency-weighted Bayesian concept learning over the same 45 rules (with separate prior plausibilities for even, odd and the other kinds of rule) and all intervals of 1-100 with a tempered size principle, but how strongly they apply the size principle depends on whether they are meeting a set for the first time: on the first question about a set they treat the examples as strong evidence for a small, tight concept, while on later questions about an already-familiar set the examples' evidence weighs less (a fitted change in sampling strength), so they generalize more broadly. The single change is this exposure-dependent sampling strength, motivated by the critique that a set's first trial gets fewer yeses than its later trials, which the history-blind incumbent cannot produce.
