People apply the size principle only to symbolic rules: for arithmetic, digit and digit-sum rules a small rule that fits every example is a suspicious coincidence, but for stretches of the number line an example is just a number the range happens to contain, so every range covering the examples stays credible in proportion to its prior plausibility alone (the best model's narrow-favouring, open-ended-discounted, margin-credited range prior), however wide it is and however many examples are shown. This predicts that magnitude-based generalization does not tighten as more examples fall in a cluster (about as much "yes" to 70 after 60, 62, 64 as after 60 alone), whereas rule-based generalization sharpens with each example as before.
