# Critique context

# The task

Each participant sees a few example numbers between 1 and 100, produced by a
hidden computer program, and is asked about other numbers between 1 and 100:
would the program also produce this number? The examples on a trial are its
*set* (one to four numbers, shown in the order given); the number asked about
is the *target*. The participant answers yes or no. There is no correct
answer and no feedback.

Every participant answers about many (set, target) pairs, and the same set is
asked about with many targets.

## The data

Each row of `responses.csv` is one answer:

| Column           | Meaning                                                            |
| ---------------- | ------------------------------------------------------------------ |
| `number_set`     | the example numbers, comma-separated in the order shown ("16,8,64") |
| `target`         | the number asked about, 1-100                                      |
| `rating`         | 1 if the participant answered yes (the program would produce it), else 0 |
| `trial_index`    | the trial's position in that participant's session                 |

**Incumbent model code:** `/scr/wurgaft/auto-psych/agent_trees/88c1bd3cf1e5f7a8/repo/_runs/cell_1/experiment2/model_loop/models/narrow_range_specificity_bias.py`
**Incumbent hypothesis:** People infer the hidden concept by Bayesian inference over arithmetic and digit rules and numeric ranges. They read the examples as distinct numbers drawn from the concept, allow that some are stray, and sometimes guess. The one distortion is a specificity bias in how they think about ranges: before seeing any examples, they already judge a narrow stretch of numbers a likelier program than a wide one, so a range's prior plausibility falls (or rises) as a power of its width. The rules themselves keep an equal prior. This predicts tighter "yes" gradients around clustered examples (e.g. 60, 62, 64) and fewer "yes" answers far beyond the examples' span than an unbiased learner gives, while generalization by rules (e.g. powers of 2 after 16, 8, 64) is left unchanged.
