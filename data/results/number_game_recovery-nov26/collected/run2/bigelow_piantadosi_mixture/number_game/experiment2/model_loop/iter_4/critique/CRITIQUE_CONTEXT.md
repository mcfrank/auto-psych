# Critique context

# The task

Each participant sees a few example numbers between 1 and 100, produced by a
hidden computer program, and is asked about other numbers between 1 and 100:
would the program also produce this number? The examples on a trial are its
*set* (one to four numbers, shown in the order given); the number asked about
is the *target*. The participant answers yes or no. There is no correct
answer and no feedback.

Every participant answers about many (set, target) pairs, and the same set is
asked about with many targets.

## The data

Each row of `responses.csv` is one answer:

| Column           | Meaning                                                            |
| ---------------- | ------------------------------------------------------------------ |
| `number_set`     | the example numbers, comma-separated in the order shown ("16,8,64") |
| `target`         | the number asked about, 1-100                                      |
| `rating`         | 1 if the participant answered yes (the program would produce it), else 0 |
| `trial_index`    | the trial's position in that participant's session                 |

## Your job

**Incumbent (best) model:** `margin_beyond_examples_range_prior`
**Incumbent model code:** `/scr/wurgaft/auto-psych/agent_trees/88c1bd3cf1e5f7a8/repo/_runs/cell_1/experiment2/model_loop/models/margin_beyond_examples_range_prior.py`
**Incumbent hypothesis:** Refinement of `digit_sum_open_ended_range_discount` (the incumbent): people do Bayesian concept learning over the same arithmetic and digit rules, the 18 digit-sum concepts and every numeric range of 1-100, reading the examples as distinct draws with some strays, sometimes guessing, favouring narrow ranges and discounting open-ended ranges that run to 1 or 100. The one change is a margin expectation: people do not expect the few numbers they were shown to sit right at the edges of the program's range, so they credit a candidate range by how far it reaches past the examples on either side (strength inferred; the data suggest more credit for ranges with room beyond the examples). This predicts more "yes" to numbers a little beyond either end of a cluster (e.g. 57 or 67 after 60, 62, 64) than the incumbent gives, symmetrically on both sides and regardless of the order the examples were shown in, while rule and digit-sum generalization are unchanged.
