People do not infer a hidden rule; they store the shown examples and say "yes" to a target in proportion to its summed similarity to those stored exemplars, where similarity falls off exponentially with the attention-weighted mismatch between the two numbers on a set of number dimensions (magnitude, parity, residues mod 3, 4 and 5, last digit, tens digit, digit sum, shared digits, primality, squareness, power-of-2-ness). Attention is allocated afresh for each set, shifting toward the dimensions on which the examples agree with each other (e.g. last digit after 13, 73, 43; magnitude after 60, 62, 64), with the sharpness of that shift inferred. This predicts that a target matching the examples on their common dimension gets "yes" even if far away in magnitude, while dimensions on which the examples vary are ignored.
