People judge the target by how similar it is to the examples, where similarity is measured by the tightest description they share: people find the most specific property common to all the examples (an arithmetic or digit rule, a digit sum, or the narrowest stretch of the number line that covers them) and ask how much broader that shared description must become to take in the target as well. Similarity falls off steeply (and then levels off) with this broadening, measured as the log of how many times larger the tightest shared description gets, and the more similar the target, the more likely a "yes" — there is no weighing of alternative hypotheses, only this one specificity-loss metric. This predicts "yes" to 32 after 16, 8, 64 (no loss: still powers of 2) but "no" to 20 (the shared description must widen to even numbers or 8-64), and that an extra example lying inside the examples' span (e.g. 15 after 31, 3, 1) leaves generalization unchanged rather than narrowing it.
