Refinement of the incumbent `heading_weber_upward_with_replacement`: people do the same Bayesian concept learning over arithmetic, digit and digit-sum rules and every numeric range of 1-100. They read the examples as independent draws with some strays, sometimes guess, judge a range's breadth Weber-like, stretch ranges toward the heading and expect the numbers to carry on upward past the largest example. The one change is how much weight people give the evidence as a set grows: the weight per example is not fixed but rises or falls as a power of how many examples were shown, with strength and direction inferred. So a single example is judged as before, while bigger sets sharpen belief toward narrow rules and tight ranges by more (or by less) than an ideal learner would. This predicts that adding a fourth example to a set changes how far "yes" spreads by a different amount than the incumbent predicts (e.g. 31, 3, 1 compared with 31, 3, 1, 15).
