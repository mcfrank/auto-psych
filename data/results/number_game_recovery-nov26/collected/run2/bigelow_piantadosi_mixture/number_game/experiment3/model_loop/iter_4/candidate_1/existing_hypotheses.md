# Existing hypotheses

Each model below is ONE cognitive hypothesis, with how it stands on the current data by ELPD-LOO (best first). `elpd_diff ± dse` is a model's deficit against the best and the standard error of that difference (with the responses to each stimulus pair counted together, as they are correlated): within about 2·dse the two are statistically tied on this data; beyond it the model has lost. "PSIS-LOO unreliable" means the estimate itself is untrustworthy (too many high-Pareto-k trials), not that the model is bad. Propose a hypothesis that is genuinely different from these, or a refinement of a single one of them — never a combination of several.

## position_decaying_example_evidence  — rank 0, the best model on this data, ELPD-LOO -3195.0

People read the examples one after another and build a running guess about the program, but each example revises that guess by a steadily changing amount: the evidence an example carries shrinks (or grows) by a constant factor with each step down the sequence, with the factor inferred, so the total weight of the evidence is not fixed but depends on how many examples came before. Otherwise they do plain Bayesian concept learning over arithmetic, digit and digit-sum rules and every numeric range of 1-100 (equally plausible ranges, independent draws with some strays, occasional guessing). This predicts that a later example narrows generalization less than a full-weight learner expects when evidence fades (for example, a fourth example after 31, 3, 1), and that the same numbers shown in a different order generalize toward the concepts favoured by whichever examples came first.

## set_size_scaled_evidence_weight  — rank 1, 1.8 ± 1.7 nats behind the best (1.0× dse: statistically tied with the best), ELPD-LOO -3196.8

Refinement of the incumbent `heading_weber_upward_with_replacement`: people do the same Bayesian concept learning over arithmetic, digit and digit-sum rules and every numeric range of 1-100. They read the examples as independent draws with some strays, sometimes guess, judge a range's breadth Weber-like, stretch ranges toward the heading and expect the numbers to carry on upward past the largest example. The one change is how much weight people give the evidence as a set grows: the weight per example is not fixed but rises or falls as a power of how many examples were shown, with strength and direction inferred. So a single example is judged as before, while bigger sets sharpen belief toward narrow rules and tight ranges by more (or by less) than an ideal learner would. This predicts that adding a fourth example to a set changes how far "yes" spreads by a different amount than the incumbent predicts (e.g. 31, 3, 1 compared with 31, 3, 1, 15).

## heading_weber_upward_with_replacement  — rank 2, 2.4 ± 1.8 nats behind the best (1.3× dse: statistically tied with the best), ELPD-LOO -3197.5

Refinement of the incumbent `heading_weber_with_upward_counting`: people do Bayesian concept learning over the same arithmetic, digit and digit-sum rules and every numeric range of 1-100. They allow some strays, sometimes guess, judge a range's breadth Weber-like, let the last step's direction stretch ranges toward where the sequence is heading, and expect the program's numbers to carry on upward past the largest example.
