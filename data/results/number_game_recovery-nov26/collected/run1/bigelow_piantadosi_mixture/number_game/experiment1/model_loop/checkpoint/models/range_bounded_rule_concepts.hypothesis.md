People's hypothesis space contains not only whole-number-line rules ("even numbers", "ends in 7") and numerical ranges, but also rules confined to a range ("even numbers in the 20s", "multiples of 5 below 40"); because such range-bounded rules are smaller, the size principle favours them, so people generalise a rule mainly to targets near the examples. The disagreement with the current best model lives in targets far outside the examples' range that fit a rule only by a property such as their last digit or a common multiple: the best model endorses them strongly, this one predicts that endorsement falls off with distance from the examples.
