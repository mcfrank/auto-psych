Refinement of first_guess_win_stay_concepts: people hold a single working guess about the concept (a rule or a numerical range), formed from the first example by Bayesian concept learning, keep it with a fitted stickiness while new examples fit it, and reconsider from all examples seen so far only when an example contradicts it (or they do not stick), producing a primacy effect. The one change is that rules are not equally plausible a priori: each rule (e.g. "powers of 2" versus "ends in 7") has its own fitted prior weight (the component taken from bigelow_piantadosi_independent / erlang_interval_prior_concepts), so which guess people first latch onto — and therefore which guess survives later examples — depends on how natural each rule is to them.
