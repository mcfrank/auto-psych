People do not infer a hidden rule or range; they judge a target by Tversky-style feature similarity to the examples. Each number is represented by its salient properties (parity, primality, being a square, cube or power, multiples, final digit, digits it contains, and which band of ten it falls in), each property weighted by how distinctive it is (rarer properties count more), and the target's similarity to the examples is the weighted features it shares with them relative to the features the examples have that it lacks and the features it has that the examples lack (Tversky's ratio contrast model); the probability of "yes" rises with that similarity.
