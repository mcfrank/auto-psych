Refinement of the incumbent misfit_tolerant_coincidence_rethink (a single working concept guess — a rule or a numerical range — formed from the first example by Bayesian concept learning, kept with fitted stickiness while later examples fit it, digit rules discounted and salient only once two examples share a digit, a newly noticed coincidence triggering a rethink, fitted trust in the examples, and misfitting examples sometimes written off as strays). The one change: how readily a contradicting example is written off depends on how well established the guess is — each earlier example the guess explains independently gives a fitted chance of dismissing the misfit, so a guess supported by one example is easily abandoned while one supported by two or three examples (77, 17 → "ends in 7") usually survives an outlier, and a guess supported by none is never protected.
