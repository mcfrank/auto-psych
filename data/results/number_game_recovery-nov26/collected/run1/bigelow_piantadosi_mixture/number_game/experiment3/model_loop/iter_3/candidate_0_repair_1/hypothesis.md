Refinement of the best model, gamma_width_distance_hesitant_guess. Concept learning is unchanged: a single sticky working guess (a rule, or a range with a gamma-shaped width prior) formed from the first example, digit rules salient once two examples share a digit, a newly noticed coincidence triggering a rethink, and misfits written off more readily the more examples the guess explains. People are still reluctant to extend their guessed concept far from the examples. The one change is that how far each example licenses extension depends on when it was shown: the example just seen supports a wide neighbourhood, and each earlier example supports a narrower one, shrinking by a fitted factor per later example (a fitted value of zero would mean order does not matter). So the same examples in a different order produce different gradients: after 20 then 80, a target near 80 is endorsed more than one equally near 20, and after 80 then 20 the opposite holds.
