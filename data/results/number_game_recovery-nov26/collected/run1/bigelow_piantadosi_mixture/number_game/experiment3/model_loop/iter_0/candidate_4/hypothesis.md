Refinement of the incumbent misfit_tolerant_coincidence_rethink (a single working concept guess — a rule or a numerical range — formed from the first example by Bayesian concept learning, kept with fitted stickiness while later examples fit it, digit rules discounted and salient only once two examples share the digit, a newly noticed coincidence triggering a rethink, fitted trust, and a contradicting example sometimes written off as a stray). The one change: how readily people write off a contradicting example grows with how much evidence their guess already has — each earlier example the guess explains is an independent reason to keep it, so the chance of dismissing the misfit is one minus the chance that none of those confirmations holds (the same fitted tolerance per confirming example, zero for a guess that explains nothing). So "ends in 7" survives an outlier 8 more often after 77, 17, 37 than after 77, 17, and a misfit late in a long set is shrugged off more than one early in a short set.
