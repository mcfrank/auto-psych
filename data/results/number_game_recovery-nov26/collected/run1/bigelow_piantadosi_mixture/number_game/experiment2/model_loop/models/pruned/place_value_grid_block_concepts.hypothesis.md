People do not think of the numbers 1-100 as points on a number line but as cells of a place-value grid (tens digit by ones digit), and besides familiar arithmetic rules (even, multiples, powers, squares, primes) the only concepts they entertain are blocks on that grid — a run of tens digits crossed with a run of ones digits, such as "the forties", "ends in 6", "ends in 5 to 7" or "20s and 30s ending in 3 to 7". They learn which block or rule the program uses by Bayesian concept learning with a single sticky working guess formed from the first example, so after 27 and 33 they endorse 23 and 37 (same block of digits) more than 30, which a number-line range would favour.
