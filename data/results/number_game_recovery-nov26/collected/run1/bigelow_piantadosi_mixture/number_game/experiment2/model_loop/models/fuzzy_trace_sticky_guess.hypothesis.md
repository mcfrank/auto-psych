Refinement of fuzzy_trace_example_memory: people do Bayesian concept learning over mathematical rules and numerical ranges (size principle, Erlang prior on range width) against fuzzy memory traces of the examples — each kept verbatim only with a fitted probability, otherwise only as its rough magnitude (within about five). The one change, the component taken from first_guess_win_stay_concepts: people do not weigh all the traces at once but hold a single working guess formed from the first example, keep it with a fitted stickiness while each newly remembered example fits it, and reconsider from all the traces so far only when the remembered example contradicts it — so imprecise memory weakens digit and arithmetic rules while early guesses persist, making generalisation depend on both memory precision and example order.
