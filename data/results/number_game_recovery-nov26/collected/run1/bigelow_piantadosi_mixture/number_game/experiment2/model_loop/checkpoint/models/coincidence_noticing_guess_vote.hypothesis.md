Refinement of digit_coincidence_noticing_guess (a single sticky working concept guess — a rule or a numerical range — formed from the first example by Bayesian concept learning, digit rules discounted and made salient only once a digit is noticed as shared by two examples, fitted trust in the examples). The one change, the component taken from sampled_guess_vote_threshold: people do not answer by consulting a single guess, but call to mind several guesses generated by this learner and say "yes" only if a sufficient share of them contain the target, with the effective number of guesses and the share required fitted. So the same belief maps onto a sharpened or softened, more liberal or more conservative yes rate — e.g. targets that only some plausible guesses contain (96 after 46 and 86) can be endorsed less, and near-certain members more, than probability matching predicts.
