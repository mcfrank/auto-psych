People do not compute the full Bayesian posterior over concepts; they hold a single running guess about the program (rules and numeric ranges, weighed by family plausibility, an Erlang prior on range width and the size principle) and revise it example by example in the order shown, win-stay/lose-sample style: after each new example they keep their current guess with a probability that grows with how well it explains that example, and otherwise draw a fresh guess from what all the examples so far suggest. A learned stickiness controls how readily a guess formed on the early examples survives later ones, so the same examples shown in a different order (e.g. 16, 8 vs 8, 16) can yield different generalisation, with early-formed broad guesses persisting more than an ideal Bayesian learner allows.
