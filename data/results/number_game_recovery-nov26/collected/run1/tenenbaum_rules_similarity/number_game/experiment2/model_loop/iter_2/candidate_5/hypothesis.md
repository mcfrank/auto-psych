Refinement of `centre_weighted_range_sampling` (rank 1): people do the same Bayesian concept learning over number rules and bounded numeric ranges, with the size principle, a prior mass per concept family (exception rules in their own family), an Erlang prior over range width, and the expectation that a bounded range's outputs cluster toward its middle. The one change, taken from `threshold_concepts_erlang_interval`, is that one-sided magnitude thresholds ("numbers above 60", "numbers below 20") are a distinct kind of program with their own inferred prior mass, exempt from the width prior and from centre-weighting (a threshold has no middle, so it emits its numbers uniformly). So the "edge-is-suspicious" pressure that pushes centred bounded ranges past the examples' extremes acts only on genuine ranges, while all-large or all-small sets can still be read as open-ended thresholds that run to the end of the number line.
