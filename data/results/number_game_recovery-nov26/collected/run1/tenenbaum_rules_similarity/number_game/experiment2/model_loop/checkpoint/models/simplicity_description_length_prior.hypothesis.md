People infer the hidden program as a Bayesian concept learner would — weighing number rules, bounded ranges and one-sided thresholds by how well they explain the examples, with the size principle and examples drawn without repetition — but their sense of how plausible a program is a priori comes from a single simplicity bias rather than learned preferences for particular kinds of concept: every program is penalised by the same amount for each symbol it takes to state it ("odd" is one, "multiples of 7" two, "between 23 and 41" three, "powers of 2 except 32" four). So how readily people read examples as a rule versus a range versus a threshold is fixed by description length alone, with one inferred cost per symbol.
