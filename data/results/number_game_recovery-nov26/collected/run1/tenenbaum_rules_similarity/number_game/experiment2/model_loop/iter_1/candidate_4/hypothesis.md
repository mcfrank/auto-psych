Refinement of `threshold_concepts_erlang_interval`: people do the same Bayesian concept learning over rules, bounded numeric ranges (with an Erlang prior on width) and one-sided thresholds, with the size principle and a prior mass per concept family, but the "suspicious coincidence" does not accumulate additively over examples. The one change is that each example's evidential weight scales with a learned power of how many examples were shown, so the more examples a set has, the more decisively each one favours tight concepts over broad ones (zero recovers the incumbent): generalisation narrows faster from one to four examples than an ideal learner predicts.
