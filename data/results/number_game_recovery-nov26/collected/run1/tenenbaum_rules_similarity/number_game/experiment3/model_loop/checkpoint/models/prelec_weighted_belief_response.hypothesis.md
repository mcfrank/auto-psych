People infer the hidden program as the simplest current concept learner does (equally plausible familiar number rules, digit-sum rules and numeric ranges, with the size principle), but they do not answer "yes" with exactly the probability they believe the target belongs: before responding they pass that belief through a probability-weighting function of the kind seen in risky choice (Prelec's two-parameter form), which can make weakly believed targets feel less (or more) likely and strongly believed ones more (or less) likely, around a pivot set by the data. So partly-believed targets are answered with a systematically distorted, S-shaped or inverse-S-shaped version of the belief, the same distortion for every set, and the identity recovers probability matching.
