People infer the hidden program as a Bayesian concept learner would (equally plausible familiar number rules, digit-sum rules and numeric ranges of a typical width, with the size principle), but how decisively they act on that belief depends on how much evidence they were given: their confidence grows (or shrinks) with the number of examples shown, so after one example they answer "yes" with the probability they believe the target belongs, while after each further example the same belief is pushed further toward a firm "yes" or "no". So a target believed to belong with, say, 70% is endorsed more often after four examples than after two, which no model that maps belief to answers in the same way for every set can produce.
