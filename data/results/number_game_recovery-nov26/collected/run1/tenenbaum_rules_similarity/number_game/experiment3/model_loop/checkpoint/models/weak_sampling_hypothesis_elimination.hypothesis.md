People consider the same kinds of candidate programs as an ideal concept learner — number rules (parity, primes, squares, powers, multiples, final or contained digits, digit sums), each kind with its own prior plausibility, and numeric ranges of a typical width — but they treat each example only as a test the program passed, not as a sample it generated: programs that do not contain an example are eliminated, and every program consistent with the examples keeps its prior share however large it is, with no "suspicious coincidence" favouring tight concepts. They say "yes" in proportion to how much of the surviving, prior-weighted belief contains the target, so adding consistent examples does not narrow generalisation (e.g. after 16, 8, 64 "even" stays as credible as "powers of 2").
