Refinement of `last_example_recency_weight`: people do the same Bayesian concept learning over equally plausible familiar number rules, digit-sum rules and numeric ranges of a typical width, with the size principle and the last-seen example carrying its own evidential weight. The one change is to how far people trust the examples as genuine outputs of the program. The incumbent fixes a 10% chance that any example is a random slip. Here the chance that an example is a slip is inferred, and it changes smoothly with how many examples were shown, so an odd-one-out example in a four-example set is written off more (or less) readily than one in a two-example set, which changes how tightly people generalise from small versus large sets.
