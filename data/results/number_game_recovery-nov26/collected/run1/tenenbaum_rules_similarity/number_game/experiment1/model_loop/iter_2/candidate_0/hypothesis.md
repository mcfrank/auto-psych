People do Bayesian concept learning over rules and numeric intervals with the size principle and a separate prior weight per concept family, but they do not weigh the examples equally: how strongly each example counts as evidence about the concept rises or falls steadily with its position in the sequence shown, so the last-seen (recency) or first-seen (primacy) examples dominate which concepts survive. The one change is this learned order gradient on evidence weight, with the average weight per example held at one, so a rule that fits the heavily weighted examples but not a lightly weighted one is penalised less than an equal-weight learner would.
