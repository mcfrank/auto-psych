People anchor their concept on the first example they see: they take the first example as more surely produced by the program than the later ones (by a fitted factor), treating mainly the later examples as possible slips, so a later example that breaks the pattern set up by the first is discounted as an exception while the first example itself is rarely explained away (otherwise they do the same exception-tolerant, tempered Bayesian concept learning over arithmetic rules and moderate-width ranges on a compressed number line). The same examples shown in a different order therefore lead to different generalisations: people generalise around the first example and rules containing it, and reject neighbours of an off-pattern example more when it comes later in the list.
