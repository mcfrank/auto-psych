People anchor their concept on the first example they are shown: they trust the first example as a genuine output of the program differently (by a fitted amount, expected to be more) than the later examples, which they more readily explain away as slips, while otherwise doing the same exception-tolerant Bayesian learning over rules, ranges and rule-plus-neighbourhood-exception concepts as the best model. The order of examples therefore matters: an off-pattern example shown later is discounted and its neighbours rejected, whereas an off-pattern example shown first is taken as genuine and generalised around.
