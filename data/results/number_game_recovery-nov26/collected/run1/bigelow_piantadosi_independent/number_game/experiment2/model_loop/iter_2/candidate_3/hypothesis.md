Refinement of `rule_plus_exception_concepts`: people do the same tempered, exception-tolerant Bayesian concept learning over the same 45 rules (final-digit rules salient), moderate-width ranges on a compressed number line, and rule-with-exception concepts, but the exception a rule tolerates is not a single isolated number — it is a short run of consecutive numbers ("even numbers, and also 25 to 29"), with shorter runs a priori more plausible (how fast plausibility falls with run length is fitted; a run of one gives back the original model). The one change is this exception-as-a-small-neighbourhood: when one example breaks the others' pattern (e.g. an odd number among evens), people endorse not only that example but also its close numerical neighbours, because adding a short run to a broad rule barely enlarges it, so they generalise around the off-pattern example more than the single-number-exception model predicts.
