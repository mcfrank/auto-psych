People judge whether the program would produce a target by how close it looks to the examples on a decimal place-value grid rather than on the number line: each numeral is a position given by its tens digit and its ones digit, and similarity to an example falls off exponentially with the city-block distance between them on that grid, with separately fitted sensitivities to tens-digit and ones-digit differences. The yes probability grows with the target's average grid similarity to the examples, so a distant target sharing an example's final digit (same column) or decade (same row) is endorsed, while a numerically adjacent target across a decade boundary (29 versus 30) is judged dissimilar and rejected.
