People decide what kind of program they face (a parity, prime, square/cube, power, multiples, final-digit, contained-digit or exception rule, or a stretch of the number line) largely from their first impression of the first example, and later examples only partly adjust that impression (anchoring and adjustment), while which particular concept of the favoured kind it is gets worked out from all the examples. So the same examples in a different order lead to different answers, and a set whose first example suggests a different kind than the whole set does (e.g. 50 then 2, 8, 64) keeps the first-suggested kind in play, giving "yes" to targets that only that kind contains more often than a learner who weighs all examples equally would; otherwise they answer as the best model does, including its shift of criterion with doubt about which kind of rule it is.
