People judge the target by its similarity to the prototype of the examples — the set of familiar number properties (parity, being a multiple of some number, being a square, cube or power, being prime, final digit, decade) that all the examples share, plus their place on the number line — using Tversky's ratio-of-features similarity: the salience-weighted properties the target has in common with that prototype, relative to those plus the prototype's properties the target lacks and the target's own properties the prototype lacks, with numerical closeness to the nearest example falling off exponentially and counting as one more weighted property. The more similar the target is to the prototype by this metric, the more likely they say "yes", so a target is rejected both for missing what the examples share and for having salient properties of its own that the examples do not.
