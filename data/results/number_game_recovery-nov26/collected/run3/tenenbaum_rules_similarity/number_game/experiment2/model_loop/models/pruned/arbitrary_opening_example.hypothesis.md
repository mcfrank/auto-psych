People take the first example shown as an arbitrary starting point — just some number the hidden concept contains, picked without regard to how many numbers the concept holds — and treat only the examples that follow as drawn at random from the concept, so only those later examples make them favour small concepts (the size principle). Otherwise they do the same Bayesian concept learning as the best model (rules with a family-organised prior and exception rules as their own kind, ranges judged as a typical share of the 1–100 line, mixed strong/weak sampling for the later examples). So a single example leads to broad generalisation, each further example narrows it sharply, and the same numbers in a different order give different answers depending on which one came first.
