People do not infer a hidden concept: they hold the examples in memory as exemplars and say yes to a target the more similar it is, on average, to those stored examples. Similarity is judged over familiar number properties (parity, primality, squares, cubes, powers of 2, multiples, final digit, decade, digits contained) and magnitude. Attention shifts to whatever the examples conspicuously share, with more attention the rarer the shared property is and, for magnitude, the more tightly the examples cluster. So after an all-prime set, a non-prime target mismatches every example on a heavily attended dimension and is rejected, while other primes are accepted.
