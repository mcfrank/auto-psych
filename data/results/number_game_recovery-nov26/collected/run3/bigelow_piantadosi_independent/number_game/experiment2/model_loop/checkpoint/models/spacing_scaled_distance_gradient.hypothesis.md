People judge a target by its numerical distance to the nearest example: willingness to say yes falls off exponentially (a Shepard generalization gradient) as the target moves away from the closest example on the number line. The width of that gradient is not fixed but scales with how widely spaced the examples are, so tightly clustered examples (e.g. 60, 62, 64) produce a narrow gradient that rejects numbers a few steps away, while widely spaced examples (e.g. 16, 8, 64) produce a broad gradient that accepts numbers far from any example.
