People revise their guess about the hidden rule as each example arrives, so they trust an example more the later it comes in the sequence: the chance that they set an example aside as a stray the program did not really mean falls steadily from the first example shown to the last. Everything else in how they infer the rule is as in the current best model (primitive-built rules with simplicity costs, "prime" preferred over "odd", hundred-chart ranges, the size principle and near-all-or-none commitment), so a rule that fits all the later examples but not the first one wins more often than one that fits all but the last, and reordering the same examples changes which rule people extend.
