Refinement of `graded_exemplar_concept_retrieval`: people retrieve stored number concepts (rules judged plausible by kind, magnitude ranges of 1-100) by how closely the examples resemble each concept's members on the number line, allowing for stray examples, and endorse a target by its closeness to the nearest member of the retrieved concepts. The one change, taken from `first_example_anchored_reliability`, is that the first example shown anchors retrieval: it is trusted to come from the concept at its own, inferred level of trust, while only the later examples are pooled into the uncertain judgement of how often the program produces strays. So an off-pattern number shown first constrains which concept is retrieved differently from the same number shown later, and the same set in a different order generalises differently.
