Refinement of `family_pooled_win_stay_lose_sample`: people learn the concept one example at a time, holding a single working guess (a rule or magnitude range, picked by size-principle Bayesian concept learning under a family-organised rule prior) that they keep with some probability while it still contains each new example and otherwise re-pick from the posterior given the examples so far, so early examples shape generalisation more than later ones. The one change, taken from the incumbent `family_pooled_uncertain_reliability`, is the posterior guesses are re-picked from: instead of trusting a fixed 90% of examples, people are unsure how reliable the program is and average over that uncertainty, so strays are correlated within a set — an example that breaks a tight rule makes the rest suspect and pushes re-picked guesses toward broader concepts, while a fully consistent prefix strongly favours the tight rule.
