People take the examples one at a time, in the order shown, and hold a single working guess about the program (a mathematical rule, a rule held within a magnitude range, or a magnitude range) instead of weighing all possibilities at once. Their first guess, and any re-guess, is drawn from ordinary Bayesian concept learning over the examples seen so far: equally plausible rules, the size principle, an uncertain stray rate with sometimes-familiar strays, and a rule-versus-range expectation that varies from judgement to judgement. When a new example arrives, people keep their current guess with some inferred probability if it still contains that example, and otherwise re-guess. So a concept adopted from the early examples, such as a broad rule or a wide range, survives later examples it happens to contain, and the same set shown in a different order generalises differently.
