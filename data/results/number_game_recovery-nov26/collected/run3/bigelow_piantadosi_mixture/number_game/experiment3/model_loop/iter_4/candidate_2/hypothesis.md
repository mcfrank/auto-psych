People judge each target by Bayesian concept learning over the examples in front of them (equally plausible mathematical rules, rules held within a magnitude range, magnitude ranges of 1-100 with the lowest-to-highest-example range especially salient, the size principle, an uncertain stray rate with sometimes-familiar strays, and a rule-versus-range expectation that varies across judgements), but because different example sets are interleaved in a session, the concept from the most recent other example set they judged sometimes intrudes (proactive interference): on a small, stated share of judgements (about 1%) they check the target against the previous set's concept instead of the current one. So the same (set, target) question is answered differently depending on which set preceded it, with stray "yes" answers to targets that fit the preceding set's concept but not the current one.
