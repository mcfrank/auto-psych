People infer the hidden program by Bayesian concept learning over equally plausible mathematical rules, rules held within a magnitude range, and magnitude ranges of 1-100 (the size principle, an uncertain belief about how often an example is a stray, strays sometimes familiar numbers), but their memory for the examples is limited: each example is kept verbatim only with some inferred probability, and otherwise only its gist, its rough place on the number line, is kept. A gist-only example still supports a range covering that stretch as strongly as before, but supports a mathematical rule only as much as the rule happens to have members nearby, so when examples sit close together people often reason from their magnitudes and fill in the rule's non-members inside the examples' span (e.g. 44 after 37, 57), while for widely spread examples the gist supports only wide, weak ranges and the rule still wins.
