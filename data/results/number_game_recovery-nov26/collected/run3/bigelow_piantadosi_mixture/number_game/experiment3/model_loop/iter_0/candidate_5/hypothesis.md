Refinement of `two_source_program_concepts`: people think the hidden program may run two sources at once, a main concept (a mathematical rule or a magnitude range of 1-100, learned with the size principle and an uncertain belief about how many examples come from it) and a secondary source behind the off-pattern examples that is either random glitches or a second program they generalise from. The one change is what that second program can be: it is drawn from the same prior over programs people use for the main concept, so it can be a magnitude range as well as a rule, with no new free parameter. So off-pattern examples that cluster in magnitude (e.g. 91 and 95 among 13, 23, 43) are read as a second, range-based source, and people say "yes" to numbers near them, just as off-pattern members of a small rule license that rule's other members.
