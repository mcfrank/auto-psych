Refinement of `uncertain_reliability_noise_concepts`: people do the same Bayesian concept learning over the 45 rules (each with its own inferred prior weight) and all intervals of 1-100 with the size principle, and are just as unsure how reliable the program is on each set — but they think of a stray example as a number that some *other* mathematical rule produced (a rule picked by how plausible they find rules, then any of its members), rather than a draw that is equally likely to be any number from 1 to 100. The one change is this rule-generated stray distribution: examples that many small rules produce (1, 2, 4, 8, 16, 64, 81, 100) are easily written off as strays, so they constrain the concept less, while "unremarkable" examples that few rules produce (e.g. 58, 87, 94) are hard to dismiss and the concept must cover them.
