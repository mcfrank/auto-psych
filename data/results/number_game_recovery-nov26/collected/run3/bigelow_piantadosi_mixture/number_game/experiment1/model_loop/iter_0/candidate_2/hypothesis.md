People infer the hidden concept by Bayesian generalization over rules and intervals, but they do not weigh the examples equally: how much an example counts as evidence depends on where it came in the order shown. One serial-position gradient, inferred from the data, can favour the first examples (primacy) or the most recent ones (recency). So a concept that fits the heavily weighted examples is endorsed even if it fits the others poorly, and the same set shown in a different order would give a different pattern of generalization.
