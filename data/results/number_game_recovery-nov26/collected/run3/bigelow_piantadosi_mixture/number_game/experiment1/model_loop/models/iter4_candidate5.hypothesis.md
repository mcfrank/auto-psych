Refinement of `win_stay_lose_sample_concepts`: people learn the concept one example at a time, holding a single working guess (a rule or magnitude range) that they keep with some probability while it still contains each new example and otherwise re-pick from the Bayesian posterior given the examples so far, so early examples shape generalisation more than later ones. The one change, taken from `uncertain_reliability_noise_concepts`, is the posterior people re-pick from: they are unsure how reliable the program is and average over that uncertainty, so strays are correlated within a set. One example that breaks a tight rule makes the remaining ones suspect too and pushes re-picked guesses toward broader concepts, while a fully consistent prefix strongly favours the tight rule. This predicts order effects (from the sticky guess) that interact with how consistent the early examples are.
