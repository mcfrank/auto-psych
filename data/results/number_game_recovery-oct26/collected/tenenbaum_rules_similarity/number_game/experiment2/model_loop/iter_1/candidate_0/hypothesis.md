People judge a target by its similarity to the example set as a whole, not by inducing a concept: the psychological similarity is the share of the properties that all the examples have in common (parity, multiples, final digit, contained digit, powers, primes, squares, cubes, decade) that the target also has, each property counted by how distinctive it is (rarer properties count more), together with how close the target is in magnitude to the nearest example on a compressed (logarithmic) distance scale. The probability of "yes" rises smoothly with this similarity, so a target matching the set's distinctive shared properties and lying near an example is accepted, and acceptance falls off gradually — never all-or-none — as it loses shared properties or moves away.
