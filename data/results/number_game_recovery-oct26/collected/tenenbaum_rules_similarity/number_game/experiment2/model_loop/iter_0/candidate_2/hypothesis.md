People do Bayesian concept learning over arithmetic rules and ranges of 1-100 (kind-level rule prior, size principle, a width prior with a preference for decade-bounded ranges), but they generalize only from the examples still in working memory, and memory follows the order of presentation: the last example shown is always held, and each earlier example is lost with a probability that grows the further back it was shown (retention decays geometrically with the number of examples that came after it). So the same examples shown in a different order lead to different generalization, pulled toward the concepts the most recent examples suggest.
