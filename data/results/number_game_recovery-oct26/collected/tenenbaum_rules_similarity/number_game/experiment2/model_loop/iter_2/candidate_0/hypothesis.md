People do not infer one concept from the examples jointly; they store each example as a separate exemplar and judge the target by its similarity to each stored exemplar, where the similarity of a target to one exemplar is Shepard's consequential-region generalization (how likely a familiar number concept — an arithmetic rule, or a range with a preference for moderate, decade-bounded widths — that contains that exemplar also contains the target). The similarities are then combined conjunctively, as a soft minimum dominated by the least similar exemplar (the target must resemble every example, with an inferred degree of strictness), so a target is accepted only if it fits with all of the examples, but adding examples never tightens generalization by the size principle beyond what each exemplar alone implies.
