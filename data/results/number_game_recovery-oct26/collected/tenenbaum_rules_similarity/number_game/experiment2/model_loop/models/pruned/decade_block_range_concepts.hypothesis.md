People do Bayesian concept learning over arithmetic rules (powers, multiples, final digit, contained digit, primes, even, odd, squares, cubes; rules of one kind equally likely a priori) and numeric ranges, with the size principle, but they only ever think of ranges as whole blocks of decades ("the 80s and 90s", "1 to 30", "41 to 60") — never as a range with arbitrary ends hugging the examples. So range-based generalization is all-or-none within a decade: a target in the same decade block as the examples is accepted as readily as one right next to them, and acceptance drops abruptly at decade boundaries, with no gradient tied to the examples' exact span.
