Attenuated solitary perceptual oddity listener with twin contrast, evaluative valence framing, familiarization base rates, and visual feature complexity. Listeners interpret referring expressions by integrating visual feature complexity expectations and contextual familiarization base rates with evaluative valence framing and a solitary perceptual oddity heuristic that operates exclusively when a unique solitary singleton contrasts against an identical twin pair. When no informative expression is heard, listeners choose candidate referents by joint solitary oddity pop-out, prior familiarization frequency, evaluative valence framing, and descriptive visual feature complexity; when an informative referring expression is heard, selective attention to semantic applicability directs choice among matching referents, preserving solitary oddity pop-out when contrasting with twins, familiarization base rates, and evaluative valence attitude.

### Refinement details relative to twin_contrast_valence_base_rate_listener
- **Single stated change**: Extended twin_contrast_valence_base_rate_listener by incorporating visual feature complexity weighting into the ungrounded prior over candidate referents from twin_contrast_feature_prior_listener.
- **Why it should fit better**: On uninformative prior trials lacking twin contrast (no identical duplicates) and lacking pre-test familiarization, the source model predicts an uninformative uniform choice distribution across candidate referents regardless of visual feature complexity. However, human participants show a systematic communicative and perceptual preference for feature-rich, descriptive exemplars over sparse or featureless objects. Incorporating visual feature complexity weighting into ungrounded prior expectations allows the model to predict these descriptive complexity preferences on neutral prior displays, while preserving twin-contrast solitary oddity pop-out when identical duplicates are present, evaluative valence modulation under positive ("favorite") and negative ("least favorite") framing, and empirical familiarization base-rate sensitivity.
- **Recursion depth**: Unchanged at depth 0 (`choice_probs` evaluates `L_heur` directly without recursive speaker simulation).
- **Parameters added or removed**: Added parameter `w_feat` (prior Normal(0.0, 1.0)); retained parameter `beta_prior` (prior Normal(0.0, 2.0)), parameter `beta_utt` (prior Normal(0.0, 2.0)), parameter `w_valence` (prior Normal(0.0, 2.0)), parameter `w_base` (prior Normal(0.0, 2.0)), and parameter `lapse` (prior Beta(1.0, 9.0)).

In `choice_probs`, updated the ungrounded prior calculation from `prior = softmax_prior(params["beta_prior"] * is_singleton + valence_bias + params["w_base"] * base_rate)` to `prior = softmax_prior(params["beta_prior"] * is_singleton + valence_bias + params["w_base"] * base_rate + params["w_feat"] * ctx.feature_count)`, incorporating visual feature complexity into ungrounded prior choices while leaving `L_heur` unchanged.
