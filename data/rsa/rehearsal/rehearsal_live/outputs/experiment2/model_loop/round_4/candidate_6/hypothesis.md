Attenuated solitary perceptual oddity listener with twin contrast, evaluative valence framing, visual color contrast, contextual familiarization base rates, and feature economy. Listeners interpret referring expressions by combining contextual familiarization base rates, visual color contrast, evaluative valence framing, and twin-contrast solitary oddity with a feature economy heuristic that penalizes extraneous unmentioned properties during semantic comprehension. When an informative referring expression is produced, listeners prefer candidate referents with the fewest extraneous visual features while continuing to weight candidate referents by their familiarity, coloration, and evaluative attitude; on uninformative prior displays without an informative expression, choices track baseline solitary oddity, familiarization frequency, color contrast, and evaluative attitude.
