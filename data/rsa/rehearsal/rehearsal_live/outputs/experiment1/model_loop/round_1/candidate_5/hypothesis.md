Attenuated perceptual oddity listener. Listeners interpret referring expressions using a perceptual oddity heuristic whose salience is strong in ungrounded prior expectations but attenuated during linguistic comprehension. When hearing no informative expression, listeners spontaneously target the unique visual singleton with full pop-out strength. When hearing an informative word, top-down semantic constraints compete with bottom-up visual pop-out, dampening the singleton preference among matching referents.

Refining oddity_heuristic_listener: The source model enforced an identical oddity bias across both prior expectations and utterance comprehension. We decouple this mechanism into separate prior and utterance oddity weights, which fits better because spoken words focus attention on semantic applicability and attenuate raw visual pop-out. Differences from source: recursion depth is unchanged at depth 0 (calling L_heur); removed parameter beta; added parameters beta_prior (for uninformative prior trials) and beta_utt (for informative utterance trials); in choice_probs, prior uses beta_prior * is_singleton and heard uses L_heur with beta_utt instead of sharing beta across both.
