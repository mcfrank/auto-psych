Listeners interpret referring expressions using the mutual exclusivity principle: when an uttered feature applies to multiple referents, listeners penalize any candidate referent that possesses an exclusive, contextually unique feature that the speaker could have used to refer to it unambiguously. On displays where all items are distinct (such as a classic scalar implicature display with a one-feature target, a two-feature competitor, and a distractor), the mutual exclusivity listener strongly favors the target because the competitor possesses an exclusive identifying feature, disagreeing sharply with the perceptual oddity heuristic which predicts an equal split because all items lack identical duplicates. On uninformative prior trials without an informative word, choices default to uniform guessing.
