Listeners expect speakers to refer to objects with higher communicative success, placing a prior over candidate referents proportional to the informativeness of the best referring expression available for each object in the context. A speaker is far more likely to target an object that can be clearly and uniquely distinguished from context competitors than an ambiguous or featureless object that cannot be reliably named. In pragmatic comprehension, listeners invert an informative speaker using this communicative success prior, while on uninformative prior trials without an informative word, listener choices track expected communicative success directly.
