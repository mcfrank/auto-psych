Twin-contrast solitary perceptual oddity listener with visual feature complexity prior. Listeners interpret referring expressions by integrating a solitary perceptual oddity heuristic with baseline visual feature complexity expectations, where an odd-one-out pop-out bias operates exclusively when a solitary singleton contrasts against an identical twin pair rather than majority triplets or clusters. On uninformative prior trials without an informative word, when visual displays lack twin contrast, listeners expect speakers to target richer, feature-laden exemplars with greater descriptive complexity; when an informative referring expression is heard, selective attention to semantic applicability directs choice among matching referents, preserving solitary oddity pop-out when contrasting with twins.

### Refinement details relative to twin_contrast_solitary_oddity_listener
- **Single stated change**: Extended twin_contrast_solitary_oddity_listener by incorporating visual feature complexity weighting into the ungrounded prior over candidate referents. The source model assumed a completely uniform baseline expectation over referents whenever no twin contrast was present; incorporating feature complexity allows listeners on uninformative prior trials to favor richer, feature-laden items over sparse items when no twin contrast directs attention, while preserving solitary oddity pop-out on twin displays and literal semantic matching during utterance comprehension.
- **Why it should fit better**: In visual reference games where no informative expression is provided (prior trials), participants exhibit a pronounced visual and communicative preference for feature-rich objects over minimal, featureless objects. The source model predicted uniform choice on all prior displays lacking identical duplicates, underpredicting choices for complex objects and overpredicting choices for sparse items; weighting ungrounded expectations by feature complexity captures this baseline preference across distinct displays while leaving displays with identical feature counts (such as the solitary prior condition in auto_psych) completely unaffected because uniform feature counts contribute identical additive constants that cancel out under softmax normalization.
- **Recursion depth**: Unchanged at depth 0 (`choice_probs` evaluates `L_heur` directly without recursive speaker simulation).
- **Parameters added or removed**: Added parameter `w_feat` (prior `Normal(0.0, 1.0)`); retained parameter `beta_prior` (prior `Normal(0.0, 2.0)`), parameter `beta_utt` (prior `Normal(0.0, 2.0)`), and parameter `lapse` (prior `Beta(1.0, 9.0)`).
- **Code differences**: In `PARAMS`, added `"w_feat": dist.Normal(0.0, 1.0)`. In `choice_probs`, updated the prior calculation to `prior = softmax_prior(params["beta_prior"] * is_singleton + params["w_feat"] * ctx.feature_count)`. `L_heur` and `compute_singleton_indicator` remain identical to the source model.
