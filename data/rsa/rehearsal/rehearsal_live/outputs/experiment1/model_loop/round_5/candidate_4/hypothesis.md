Attenuated solitary perceptual oddity listener with twin contrast and continuous contextual distinctiveness. Listeners interpret referring expressions by integrating a solitary perceptual oddity heuristic with continuous visual distinctiveness, where bottom-up oddity pop-out operates exclusively when a solitary singleton contrasts against an identical twin pair rather than majority clusters. In both spontaneous ungrounded prior expectations and linguistic utterance comprehension, candidate referents are additionally weighted by their continuous contextual distinctiveness (overall feature contrast relative to other objects in the display), favoring objects that stand out from the visual context while defaulting to uniform baseline expectations across referents when displays lack twin contrast and distinctiveness asymmetries.

### Refinement details relative to twin_contrast_solitary_oddity_listener
- **Single stated change**: Extended twin_contrast_solitary_oddity_listener by incorporating the continuous contextual distinctiveness component from rsa_l2_singleton_feat_color_valence_l0. The source model treated all candidate referents as having equal baseline salience whenever no twin contrast was present, ignoring whether an object differed from other items by one feature or by many features; incorporating continuous contextual distinctiveness allows listeners to weight candidate referents by their total feature distance from the rest of the display in both prior expectations and utterance comprehension, while preserving twin-contrast solitary oddity pop-out on twin displays.
- **Why it should fit better**: In visual reference games with diverse objects, items that differ markedly in visual features from their neighbors attract visual attention and stand out as prominent figures against the ground. The source model predicts an equal split across all distinct referents satisfying literal semantics, underpredicting choices for items that have greater feature contrast with the context; incorporating contextual distinctiveness captures this continuous visual contrast across all display shapes while preserving the solitary oddity boost on displays with duplicate twins.
- **Recursion depth**: Unchanged at depth 0 (`choice_probs` evaluates `L_heur` directly without recursive speaker simulation).
- **Parameters added or removed**: Added parameter `w_distinct` (prior `Normal(0.0, 1.0)`); retained parameter `beta_prior` (prior `Normal(0.0, 2.0)`), parameter `beta_utt` (prior `Normal(0.0, 2.0)`), and parameter `lapse` (prior `Beta(1.0, 9.0)`).
- **Code differences**: In `PARAMS`, added `"w_distinct": dist.Normal(0.0, 1.0)`. Added helper `compute_distinct(ctx)` computing `jnp.sum(jnp.abs(real_lex[:, :, None] - real_lex[:, None, :]), axis=(0, 2))` where `real_lex = ctx.lex * (1.0 - ctx.is_sink[:, None])`.
