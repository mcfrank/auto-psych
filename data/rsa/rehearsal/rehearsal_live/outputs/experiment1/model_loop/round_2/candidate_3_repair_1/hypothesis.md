Listeners interpret referring expressions using graded semantic truth values rather than binary all-or-nothing semantics, judging a word's applicability to degrade as candidate referents possess extraneous visual features that dilute the word's prototypicality. Communicative speakers balance this graded truth against listener recovery when selecting words, while listeners invert the speaker and prioritize referents by their contextual feature complexity when no informative word is heard. A lapse parameter captures random clicking.
