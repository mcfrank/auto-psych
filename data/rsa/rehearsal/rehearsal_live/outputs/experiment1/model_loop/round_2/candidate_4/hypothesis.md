Attenuated solitary perceptual oddity listener. Listeners interpret referring expressions using a solitary perceptual oddity heuristic whose salience is strong during ungrounded prior expectations but attenuated during linguistic utterance comprehension. When no informative expression is heard, listeners spontaneously select the unique solitary singleton with full bottom-up pop-out strength; when an informative referring expression is heard, top-down semantic constraints compete with bottom-up visual pop-out, dampening the solitary singleton bias among semantically matching referents.

### Refinement details relative to solitary_oddity_heuristic_listener
- **Single stated change**: Decoupled the solitary oddity weighting parameter into separate uninformative prior (`beta_prior`) and linguistic utterance comprehension (`beta_utt`) weights. Spoken referring expressions draw selective attention to semantic truth conditions, which attenuates bottom-up perceptual oddity pop-out relative to spontaneous prior expectations.
- **Recursion depth**: Unchanged at depth 0 (`choice_probs` evaluates `L_heur` directly without recursive speaker simulation).
- **Parameters added or removed**: Removed parameter `beta`; added parameters `beta_prior` (prior Normal(0.0, 2.0)) and `beta_utt` (prior Normal(0.0, 2.0)); retained parameter `lapse` (prior Beta(1.0, 9.0)).
- **Code differences**: In `PARAMS`, replaced `beta` with `beta_prior` and `beta_utt`. In `L_heur`, replaced `beta` with `beta_utt`. In `choice_probs`, `prior` is computed using `params["beta_prior"] * is_singleton` and `heard` evaluates `L_heur(params["beta_utt"], ctx.lex, is_singleton)[ctx.utterance]`, decoupling the ungrounded prior and grounded utterance choice pathways.
