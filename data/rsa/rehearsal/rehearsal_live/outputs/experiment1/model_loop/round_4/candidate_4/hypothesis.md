Attenuated solitary perceptual oddity listener with twin contrast and visual color contrast. Listeners interpret referring expressions using an attenuated solitary perceptual oddity heuristic where bottom-up oddity pop-out operates exclusively when a solitary singleton contrasts against an identical twin pair rather than majority clusters, while additionally favoring visually prominent, fully colored referents over desaturated grayscale distractors. In both spontaneous ungrounded prior expectations and linguistic utterance comprehension, candidate referents are weighted by both twin-contrast solitary oddity pop-out and visual color contrast, defaulting to uniform baseline expectations across referents when visual displays lack twin contrast and chromatic asymmetries.

### Refinement details relative to twin_contrast_solitary_oddity_listener
- **Single stated change**: Extended twin_contrast_solitary_oddity_listener by incorporating the visual color contrast component from rsa_l2_singleton_feat_color_valence_l0. The source model treated chromatic and achromatic objects identically, ignoring whether candidate referents were presented in full color or desaturated grayscale; incorporating visual color contrast allows listeners to favor visually prominent, fully colored referents over desaturated grayscale distractors in both spontaneous prior expectations and utterance comprehension, while preserving twin-contrast solitary oddity pop-out and uniform baseline choice on neutral, all-color displays.
- **Why it should fit better**: In reference games presenting chromatic target items alongside desaturated grayscale distractors, participants exhibit a prominent visual pop-out bias toward fully colored referents. The source model predicts equal choice probabilities across colored and grayscale referents satisfying literal semantics, underpredicting choices for colored targets; incorporating visual color contrast captures this perceptual pop-out effect on displays with color variation while leaving displays without grayscale variation (including all auto_psych conditions) completely unaffected because uniform coloration contributes identical additive constants that cancel out under softmax normalization.
- **Recursion depth**: Unchanged at depth 0 (`choice_probs` evaluates `L_heur` directly without recursive speaker simulation).
- **Parameters added or removed**: Added parameter `w_color` (prior Normal(0.0, 2.0)); retained parameters `beta_prior` (prior Normal(0.0, 2.0)), `beta_utt` (prior Normal(0.0, 2.0)), and `lapse` (prior Beta(1.0, 9.0)).
- **Code differences**: In `PARAMS`, added `"w_color": dist.Normal(0.0, 2.0)`. In `L_heur`, added parameter `color_bias: ...` and updated the referent choice weighting expression to `at(lex, u, r) * exp(beta_utt * vec(is_singleton, r) + vec(color_bias, r))`. In `choice_probs`, computed `color_bias = params["w_color"] * (1.0 - ctx.grayscale)`, added `color_bias` to the prior calculation (`prior = softmax_prior(params["beta_prior"] * is_singleton + color_bias)`), and passed `color_bias` to `L_heur`.
