Listeners evaluate referents through a perceptual salience prior governed by visual feature complexity and chromatic pop-out. In neutral displays where all objects share the same chromatic format, listeners favor simpler referents with fewer extraneous features as default prototypes. When an object is rendered in full color against grayscale distractors, chromatic contrast produces visual pop-out that captures attention, boosting that object's prior probability both when interpreting a description and on uninformative prior trials.
