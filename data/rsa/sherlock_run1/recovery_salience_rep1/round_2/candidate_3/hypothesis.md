People evaluate word meanings with graded truth values rather than all-or-nothing Boolean truth conditions. A feature label provides a complete, high-truth description for an object possessing solely that feature, but acts as a diluted, partial description for an object burdened with extraneous unmentioned features. The pragmatic listener inverts a communicative speaker who optimizes informativeness over these graded semantic truth values, selecting referents based on feature specificity without any baseline bias on uninformative trials.
