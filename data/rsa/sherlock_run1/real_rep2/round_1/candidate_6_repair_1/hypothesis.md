Listeners perform depth-2 recursive pragmatic reasoning by inverting an informative speaker who simulates a depth-1 pragmatic listener, while maintaining a shared salience prior across all interlocutors that incorporates perceptual color distinctiveness alongside feature count and familiarization. When an object is rendered in color while competitor objects are displayed in grayscale, interlocutors mutually treat the colored object as having heightened visual salience, elevating both prior expectations and pragmatic referent choice toward the colored item. Compared to rsa_l2_shared_prior, recursion depth is unchanged at depth 2 (choice_probs calls L2), the parameter w_color is added to weight color distinctiveness in the object salience prior, no parameters are removed, and the color term is added to the log-salience linear predictor before softmax.
