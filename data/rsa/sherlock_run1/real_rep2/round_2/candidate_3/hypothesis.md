Listeners interpret referring expressions under the assumption that word meanings have graded truth values rather than crisp boolean applicability: a word's semantic truth value dilutes as an object accumulates unmentioned, extraneous features. A literal listener evaluates candidate referents using these graded truth values alongside perceptual salience, an informative speaker chooses utterances evaluated under this graded literal listener, and a pragmatic listener inverts the speaker. Consequently, listeners strongly favor minimal, prototypical referents whose features match the description without extraneous clutter.
