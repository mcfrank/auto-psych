People interpret referential descriptions by inverting a speaker constrained by lexical preemption: when an intended referent possesses a dedicated unique descriptor, the speaker is strongly penalized for choosing an ambiguous shared word instead. Pragmatic listeners invert this preemption constraint, ruling out candidate referents that have dedicated unique identifiers when hearing an ambiguous descriptor. On displays where a shared word matches both an object with a unique alternative feature and an object with only shared features, this model predicts listeners will sharply reject the object with the unique feature, directly opposing the best model whose distinctiveness prior boosts that same object.
