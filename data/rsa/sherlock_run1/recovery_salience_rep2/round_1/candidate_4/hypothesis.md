Listeners integrate empirical familiarization base rates into depth-2 pragmatic reasoning, using prior exposure frequencies as an object prior in Bayes' rule rather than assuming referents are equiprobable. When an informative word is heard, base rates modulate pragmatic reference resolution, and when no informative word is heard, base rates directly guide prior expectations. Compared to rsa_l2, this retains depth-2 recursion (calling L2) and the same parameters (alpha and lapse), but equips L0, L1, and L2 with an object prior vector derived from familiarization frequencies when available, replacing uniform prior choices on uninformative trials.
