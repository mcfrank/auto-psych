We refine softmax_belief_salience_listener by hypothesizing that listeners incorporate visual color contrast into object salience, expecting speakers to refer to full-color objects over grayscale ones and defaulting toward full-color objects during attentional lapses, incorporating the color-salience mechanism from color_salience_shared_prior. Because visual color contrast captures bottom-up attention, full-color objects are perceptually more prominent than grayscale alternatives both when evaluating communicative evidence and when cognitive attention lapses. Relative to softmax_belief_salience_listener, recursion depth remains unchanged at L1, one parameter w_color is added with prior Normal(0.0, 1.0), no parameters are removed, and the color salience weight multiplies the color indicator (1 minus grayscale) in the salience prior logits.
