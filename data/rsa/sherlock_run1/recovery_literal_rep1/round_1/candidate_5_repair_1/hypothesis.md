Listeners incorporate visual color contrast into object salience, expecting speakers to refer to full-color objects over grayscale ones. This color-salience preference is shared as common knowledge between speaker and listener in depth-1 pragmatic reasoning. Relative to rsa_l1_shared_prior, recursion depth remains unchanged at L1, one parameter w_color is added to the salience prior with a Normal(0, 1) prior, no parameters are removed, and the color salience weight multiplies the color indicator (1 minus grayscale) in the shared prior logits.
