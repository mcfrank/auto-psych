Speakers in reference games adhere to Gricean clarity by penalizing referentially ambiguous expressions only to the extent that the ambiguity is avoidable—that is, when a less ambiguous alternative expression was available for the intended referent. When an intended referent cannot be uniquely named because all its descriptive features are shared, using an ambiguous word is a communicative necessity and incurs no excess ambiguity penalty. Pragmatic listeners invert this avoidable-ambiguity-averse speaker under capacity-limited executive attention: hearing an ambiguous word provides strong evidence for referents where ambiguity was unavoidable, while penalizing complex competitors that possessed distinguishing alternatives.
