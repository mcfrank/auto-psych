Pragmatic listener at depth 2 under capacity-limited visual attention with focal candidate contrast set mentalizing and contrastive outlier pop-out. Refining focal_candidate_attention_listener by incorporating the contrastive outlier pop-out component from prototype_typicality_outlier_listener: when a referring expression is true of all objects in a scene except exactly one, the shared feature creates a contrastive perceptual background that isolates the solitary non-matching object as a visual outlier, occasionally capturing listener choices despite the lack of semantic fit. Counterfactual communicative mentalizing is restricted to the active focal set of candidate referents matching the heard word, so distinguishing features that isolate a competitor within the focal set strongly preempt that competitor, which directly elevates choices of multi-feature pragmatic targets over all-feature competitors in four-object displays (four_object_multifeature_target_vs_all_feature_rate and four_object_two_feature_target_vs_three_feature_competitor_rate) while outlier pop-out captures solitary non-matching foil selections.
