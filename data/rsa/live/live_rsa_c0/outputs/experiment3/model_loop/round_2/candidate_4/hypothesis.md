Speakers in reference games adhere to Gricean clarity by penalizing referentially ambiguous expressions specifically when the ambiguity is avoidable—that is, when the intended referent possessed an alternative distinguishing expression that would have uniquely identified it in context. When an intended referent cannot be uniquely singled out because all its descriptive features are shared, producing an ambiguous expression is a communicative necessity and incurs no avoidable ambiguity penalty. Pragmatic listeners invert this avoidable-ambiguity-sensitive speaker under capacity-limited executive attention, while visual scenes isolating a solitary non-matching object trigger contrastive outlier pop-out that occasionally captures listener choices.

Refining avoidable_ambiguity_speaker by incorporating the contrastive outlier pop-out component from prototype_typicality_outlier_listener: when a referring expression is true of all objects in a visual scene except exactly one, the shared feature creates a contrastive perceptual background that isolates the solitary non-matching object as a visual outlier, occasionally capturing listener choices despite the absence of semantic fit. This contrastive pop-out mechanism directly rectifies the observed distractor intrusion rate on three-object displays where solitary non-matching foils are chosen significantly more often than standard pragmatic suppression predicts (three_object_one_feature_target_vs_two_feature_competitor_rate), while fully preserving avoidable ambiguity speaker reasoning, executive attention allocation, and category typicality.
