Listeners interpret referring expressions under capacity-limited visual attention that restricts counterfactual communicative mentalizing to the active focal set of candidate referents matching the heard word. When evaluating what a speaker would have said, listeners mentally simulate alternative expressions only with respect to distinguishing candidates within this attended contrast set, rather than tracking distractors already ruled out by the literal word. Consequently, distinguishing features that isolate a competitor within the focal candidate set strongly preempt that competitor, elevating choices of minimal pragmatic targets in multi-candidate displays.
