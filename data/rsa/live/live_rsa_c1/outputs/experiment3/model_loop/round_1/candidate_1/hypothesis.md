Speakers choose utterances based on visual feature salience in the display: descriptors that are rare in the visual context pop out pre-attentively, making speakers preferentially produce distinctive features over ubiquitous shared features. Pragmatic listeners invert this feature-salience speaker, inferring that hearing an ambiguous shared descriptor indicates the speaker intended a referent that lacked salient visual alternatives. In the absence of an informative descriptor on mumble trials, visual attention is drawn pre-attentively to the object with the highest visual feature complexity.
