In visual reference games, speakers balance communicative informativeness against the cognitive effort of vocabulary specificity, incurring an utterance cost when deploying an exclusive, idiosyncratic feature that describes only a single object in the visual scene compared to using a shared, grounded category label. When communicating about an overspecified competitor object that possesses both a shared attribute and an exclusive distinguishing feature, speakers frequently avoid this specificity cost and produce the shared label instead. Depth-2 pragmatic listeners invert this specificity-averse speaker, expecting shared words to frequently refer to complex competitor objects and naturally softening recursive preemption penalties in scalar reference games.
