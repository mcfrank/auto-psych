We refine feature_binding_uncertainty_lapse_l2 by incorporating contrast-gated inferential precision from contrast_gated_listener_l2 into pragmatic listener reference resolution. Listeners dynamically gate their pragmatic inferential capacity by the contextual discriminative contrast of the heard expression: words that rule out context distractors license confident counterfactual preemption, whereas expressions with low or zero contrast (such as words true of all context items or shared labels in two-object subset displays) lead listeners to attenuate pragmatic precision and rely more heavily on default perceptual expectations. This mechanism directly resolves the incumbent model's significant overprediction of pragmatic targets in two-object subset contexts and ambiguous-word singleton displays while preserving perceptual feature binding and contextual lexical uncertainty.

Differences from feature_binding_uncertainty_lapse_l2:
- Recursion depth: Unchanged; choice_probs calls L_choice, which marginalizes over depth-2 pragmatic listener L2.
- Parameters added: kappa_base (prior: dist.LogNormal(0.0, 1.0)), w_contrast (prior: dist.Normal(0.0, 1.0)).
- Parameters removed: kappa.
- Pragmatic listener inferential precision: Replaces fixed inferential capacity kappa with contrast-gated inferential precision (kappa = params["kappa_base"] * jnp.exp(params["w_contrast"] * contrast)) from contrast_gated_listener_l2, where contextual contrast scales with the proportion of context objects ruled out by the utterance ((n_obj - freq) / n_obj, with 0.0 for the sink utterance), applied via vec(kappa, u) in L1 and L2.
- Perceptual feature-binding mechanism: Unchanged; non-matching distractor objects receive illusory conjunction probability scaling with relative visual feature complexity and prior salience (binding_weight = is_false * (ctx.feature_count / max_fc) * prior, normalized as p_bind), mixed into the pragmatic interpretation as p_word = (1.0 - effective_bind) * heard + effective_bind * p_bind.
- Contextual lexical feature uncertainty: Unchanged; listeners marginalize over alternative feature interpretations that co-occur in context with the uttered word via transition matrix p_feat (weighted by beta) in L_choice.
- Response choice lapse mechanism: Retains salience-captured attentional lapse mixing (p_choice = (1.0 - lapse) * p_word + lapse * prior, returning prior on uninformative prior trials).
- All other terms: Contextual feature prevalence accessibility (w_prevalence) and referential equivalence class size redundancy discounting (w_redundancy via compute_equivalence_class) on speaker alternatives in S1 and S2, literal truth-conditional semantics at L0, depth-2 RSA recursion, and shared perceptual referent prior (w_singleton, w_distinct, w_features, w_empty, w_color) remain identical to feature_binding_uncertainty_lapse_l2.
