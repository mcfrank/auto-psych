When communicating in visual reference games, speakers are partially egocentric reasoners who balance partner-directed informativeness against egocentric accessibility, frequently producing a true feature of the intended referent without checking whether it disambiguates the object from context distractors. Pragmatic listeners invert this partially egocentric speaker via recursive Theory of Mind, recognizing that hearing an ambiguous label does not decisively rule out a multi-featured competitor because an egocentric speaker often names true features regardless of distinguishing alternatives. Across displays from 2x2 to 4x4 and varying feature overlaps, this mechanism naturally softens counterfactual preemption in subset-superset displays and favors candidates with fewer total features in cross-cutting contexts because egocentric production probability scales inversely with each object's total feature count.
