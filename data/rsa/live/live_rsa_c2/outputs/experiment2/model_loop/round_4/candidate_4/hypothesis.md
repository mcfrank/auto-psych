We refine feature_binding_uncertainty_lapse_l2 by incorporating contextual end-point salience from endpoint_salience_l2 into the shared visual referent prior. In visual reference games, listeners anchor their default perceptual attention at the structural boundaries of the scene's feature complexity distribution (the minimal baseline object and the maximal exemplar), while intermediate objects that fall strictly between these poles are disfavored as unremarkable non-targets. Pragmatic listeners resolve referring expressions under this extremity prior alongside perceptual feature-binding noise and contextual lexical uncertainty, directly resolving the incumbent model's significant overprediction of strictly intermediate-complexity objects on both unprompted mumble trials and matching word trials.

Differences from feature_binding_uncertainty_lapse_l2:
- Recursion depth: Unchanged; choice_probs calls L_choice, which marginalizes over depth-2 pragmatic listener L2.
- Parameters added: w_endpoint (prior: dist.Normal(0.0, 1.0)).
- Parameters removed: None.
- Shared visual referent prior: Adds contextual endpoint salience (params["w_endpoint"] * is_endpoint) to the perceptual referent prior, where is_endpoint flags objects possessing either the minimum or maximum feature count in the display (1.0 - is_inter, where is_inter identifies objects whose feature count is strictly between the display minimum and maximum), disfavoring strictly intermediate objects.
- Perceptual feature-binding mechanism: Unchanged; non-matching distractor objects receive illusory conjunction probability scaling with relative visual feature complexity and prior salience (binding_weight = is_false * (ctx.feature_count / max_fc) * prior, normalized as p_bind), mixed into the pragmatic interpretation as p_word = (1.0 - effective_bind) * heard + effective_bind * p_bind.
- Contextual lexical feature uncertainty: Unchanged; listeners marginalize over alternative feature interpretations that co-occur in context with the uttered word via transition matrix p_feat (weighted by beta) in L_choice.
- Response choice lapse mechanism: Retains salience-captured attentional lapse mixing (p_choice = (1.0 - lapse) * p_word + lapse * prior, returning prior on uninformative prior trials).
- All other terms: Capacity-limited inferential updating (kappa) at L1 and L2, contextual feature prevalence accessibility (w_prevalence) and referential equivalence class size redundancy discounting (w_redundancy via compute_equivalence_class) on speaker alternatives in S1 and S2, literal truth-conditional semantics at L0, depth-2 RSA recursion, and baseline perceptual prior components (w_singleton, w_distinct, w_features, w_empty, w_color) remain identical to feature_binding_uncertainty_lapse_l2.
