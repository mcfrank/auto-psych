We refine prototype_feature_binding_l2 by incorporating contextual lexical feature uncertainty from contextual_feature_uncertainty_l2 into listener reference resolution. When interpreting referring expressions in visual reference games, listeners reason with contextual uncertainty about which feature in the display the speaker intended to name, evaluating alternative features in proportion to their contextual co-occurrence with the uttered label on candidate objects. Pragmatic listeners marginalize over these candidate feature interpretations via recursive Theory of Mind within an ensemble structured by contextual prototype deviance, perceptual feature binding, and salience-captured lapses, directly resolving the source model's overprediction of pragmatic targets in subset-superset displays while prototype deviance discounts intermediate non-targets and feature binding accounts for false-feature choices.
