We refine endpoint_binding_uncertainty_lapse_l2 by incorporating partially egocentric speaker production from egocentric_speaker_l2 into recursive communication. When communicating about an object, speakers balance partner-directed informativeness against egocentric accessibility, frequently producing an applicable visual feature without exhaustively verifying whether it uniquely distinguishes the referent from context distractors. Pragmatic listeners invert this partially egocentric speaker via recursive Theory of Mind at depth 2, which directly softens recursive preemption in two-object subset displays and ambiguous-word contexts while favoring candidates with fewer total features in cross-cutting contexts because egocentric production probability scales inversely with each object's total feature count.

Differences from endpoint_binding_uncertainty_lapse_l2:
- Recursion depth: Unchanged; choice_probs calls L_choice, which marginalizes over depth-2 pragmatic listener L2.
- Parameters added: w_ego (prior: dist.Beta(1.0, 4.0)).
- Parameters removed: None.
- Speaker utterance production / egocentric accessibility: In S1 and S2, candidate utterance weights interpolate between partner-directed communicative informativeness and egocentric accessibility weighted by w_ego (((1.0 - w_ego) * exp(alpha * log(L + EPS)) + w_ego)), reflecting speakers' tendency to name applicable features based on intrinsic availability without complete partner perspective-taking.
- Shared visual referent prior: Unchanged; combines singleton salience (w_singleton), contextual distinctiveness (w_distinct), visual feature count (w_features), featureless baseline ground salience (w_empty), contextual endpoint salience (w_endpoint * is_endpoint), and color contrast (w_color).
- Perceptual feature-binding mechanism: Unchanged; non-matching distractor objects receive illusory conjunction probability scaling with relative visual feature complexity and prior salience (binding_weight = is_false * (ctx.feature_count / max_fc) * prior, normalized as p_bind), mixed into the pragmatic interpretation as p_word = (1.0 - effective_bind) * heard + effective_bind * p_bind.
- Contextual lexical feature uncertainty: Unchanged; listeners marginalize over alternative feature interpretations that co-occur in context with the uttered word via transition matrix p_feat (weighted by beta) in L_choice.
- Response choice lapse mechanism: Retains salience-captured attentional lapse mixing (p_choice = (1.0 - lapse) * p_word + lapse * prior, returning prior on uninformative prior trials).
- All other terms: Capacity-limited inferential updating (kappa) at L1 and L2, contextual feature prevalence accessibility (w_prevalence) and referential equivalence class size redundancy discounting (w_redundancy via compute_equivalence_class) on speaker alternatives in S1 and S2, literal truth-conditional semantics at L0, and depth-2 RSA recursion remain identical to endpoint_binding_uncertainty_lapse_l2.
