We refine endpoint_binding_uncertainty_lapse_l2 by incorporating contextual maximal exemplar salience into the shared visual referent prior. In visual reference games, human perceptual attention does not distribute symmetrically between the structural extremes of a display; rather, the maximal feature-rich exemplar serves as the prominent visual figure that commands disproportionate communicative and perceptual focus, whereas minimal objects serve merely as baseline ground. Pragmatic listeners and speakers incorporate this maximal exemplar salience alongside baseline endpoint anchor salience into their shared referent prior, directly resolving the incumbent model's severe underprediction of full objects over empty baselines on mumble trials (mumble_full_over_empty_rate) and elevating competitor and false-feature choices on visually complex objects.

Differences from endpoint_binding_uncertainty_lapse_l2:
- Recursion depth: Unchanged; choice_probs calls L_choice, which marginalizes over depth-2 pragmatic listener L2.
- Parameters added: w_max (prior: dist.Normal(0.0, 1.0)).
- Parameters removed: None.
- Shared visual referent prior: Adds contextual maximal exemplar salience (params["w_max"] * is_max) to the perceptual referent prior alongside contextual endpoint salience (params["w_endpoint"] * is_endpoint), where is_max flags objects possessing the display maximum feature count when feature counts vary across context items ((ctx.feature_count == k_max) & (k_max > k_min)), breaking extremity symmetry to reflect the greater visual prominence and communicative focus of maximal exemplars over baseline anchors.
- Perceptual feature-binding mechanism: Unchanged; non-matching distractor objects receive illusory conjunction probability scaling with relative visual feature complexity and prior salience (binding_weight = is_false * (ctx.feature_count / max_fc) * prior, normalized as p_bind), mixed into the pragmatic interpretation as p_word = (1.0 - effective_bind) * heard + effective_bind * p_bind.
- Contextual lexical feature uncertainty: Unchanged; listeners marginalize over alternative feature interpretations that co-occur in context with the uttered word via transition matrix p_feat (weighted by beta) in L_choice.
- Response choice lapse mechanism: Retains salience-captured attentional lapse mixing (p_choice = (1.0 - lapse) * p_word + lapse * prior, returning prior on uninformative prior trials).
- All other terms: Capacity-limited inferential updating (kappa) at L1 and L2, contextual feature prevalence accessibility (w_prevalence) and referential equivalence class size redundancy discounting (w_redundancy via compute_equivalence_class) on speaker alternatives in S1 and S2, literal truth-conditional semantics at L0, depth-2 RSA recursion, and baseline perceptual prior components (w_singleton, w_distinct, w_features, w_empty, w_endpoint, w_color) remain identical to endpoint_binding_uncertainty_lapse_l2.
