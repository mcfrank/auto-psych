When resolving referring expressions in visual reference games, listeners reason under perceptual feature-binding noise (Feature Integration Theory): features active in working memory are prone to illusory conjunctions, erroneously binding to distractor objects that physically lack them. Susceptibility to illusory conjunctions scales with a distractor's visual feature complexity, directly resolving the source model's severe underprediction of literal semantic violations (false-feature choices) on complex non-matching objects while preserving bounded-capacity pragmatic inference and salience-captured attentional lapses.
