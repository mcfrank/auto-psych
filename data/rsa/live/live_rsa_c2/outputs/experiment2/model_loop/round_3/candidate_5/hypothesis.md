We refine feature_uncertainty_salience_lapse_l2 by incorporating perceptual feature-binding noise from feature_binding_listener_l2 into listener reference resolution. Under Feature Integration Theory, features active in working memory during reference games are susceptible to illusory conjunctions, erroneously binding to distractor objects in proportion to their visual feature complexity and perceptual salience. Pragmatic listeners evaluate candidate referents under contextual lexical uncertainty before subjecting non-matching objects to illusory conjunctions and salience-captured lapses, directly resolving the incumbent model's severe underprediction of semantic violations (false-feature choices) on visually complex non-matching objects while preserving bounded-capacity recursive Theory of Mind.

Differences from feature_uncertainty_salience_lapse_l2:
- Recursion depth: Unchanged; choice_probs calls L_choice, which marginalizes over depth-2 pragmatic listener L2.
- Parameters added: w_binding (prior: dist.Beta(1.0, 24.0)).
- Parameters removed: None.
- Perceptual feature-binding mechanism: In choice_probs on word trials, incorporates perceptual feature binding from feature_binding_listener_l2: non-matching distractor objects receive illusory conjunction probability scaling with relative visual feature complexity and prior salience (binding_weight = is_false * (ctx.feature_count / max_fc) * prior, normalized as p_bind), mixed into the pragmatic interpretation as p_word = (1.0 - effective_bind) * heard + effective_bind * p_bind, which then undergoes salience-captured attentional lapse mixing (p_choice = (1.0 - lapse) * p_word + lapse * prior).
- Contextual lexical feature uncertainty: Unchanged; listeners marginalize over alternative feature interpretations that co-occur in context with the uttered word via transition matrix p_feat (weighted by beta) in L_choice.
- Response choice lapse mechanism: Retains salience-captured attentional lapse mixing (p_choice = (1.0 - lapse) * p_word + lapse * prior, returning prior on uninformative prior trials).
- All other terms: Capacity-limited inferential updating (kappa) at L1 and L2, contextual feature prevalence accessibility (w_prevalence) and referential equivalence class size redundancy discounting (w_redundancy via compute_equivalence_class) on speaker alternatives in S1 and S2, literal truth-conditional semantics at L0, depth-2 RSA recursion, and shared perceptual referent prior (w_singleton, w_distinct, w_features, w_empty, w_color) remain identical to feature_uncertainty_salience_lapse_l2.
