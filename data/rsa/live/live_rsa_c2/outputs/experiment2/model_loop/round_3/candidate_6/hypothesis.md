We refine feature_binding_salience_lapse_l2 by incorporating contextual prototype deviance from prototype_deviance_prior_l2 into the shared visual referent prior. In visual reference games, listeners structure their default expectations around contextual prototype deviance: before hearing an informative word, observers automatically extract the scene's contextual prototype (the average feature profile across display objects) and expect speakers to refer to atypical, distinctive exemplars that diverge from this contextual average rather than unremarkable, prototypical items that blend into the ensemble. Pragmatic listeners integrate this prototype-deviance prior into reference resolution at depth 2 alongside perceptual feature-binding noise and salience-captured attentional lapses, directly rectifying the systematic overprediction of strictly intermediate-complexity objects on both unprompted mumble trials and matching word trials while illusory conjunctions account for choices of visually complex non-matching distractors.

Differences from feature_binding_salience_lapse_l2:
- Recursion depth: Unchanged; choice_probs calls L2.
- Parameters added: w_deviance (prior: dist.Normal(0.0, 1.0)).
- Parameters removed: None.
- Shared visual referent prior: Adds contextual prototype deviance (params["w_deviance"] * deviance) to the perceptual referent prior, where proto represents the mean occurrence of each real feature across display objects (proto = jnp.mean(real_lex, axis=1, keepdims=True)) and deviance is the L1 distance between an object's feature vector and this contextual prototype (deviance = jnp.sum(jnp.abs(real_lex - proto), axis=0)), disfavoring prototypical intermediate objects and boosting polar, distinctive exemplars across all display sizes and feature overlaps.
- All other terms: Perceptual feature-binding noise on non-matching distractors (w_binding), capacity-limited inferential updating (kappa) at L1 and L2, contextual feature prevalence accessibility (w_prevalence) and referential equivalence class size redundancy discounting (w_redundancy via compute_equivalence_class) on speaker alternatives in S1 and S2, literal truth-conditional semantics at L0, baseline prior components (w_singleton, w_distinct, w_features, w_empty, w_color), depth-2 RSA recursion, and salience-captured attentional lapse mixing remain identical to feature_binding_salience_lapse_l2.
