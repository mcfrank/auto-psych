When resolving referring expressions in visual reference games, listeners reason under the principle of Communicative Relevance (Feature Dilution): while unprompted visual attention is drawn to feature-rich objects, linguistic communication focuses attention strictly on the mentioned attribute, penalizing candidate referents in proportion to their extraneous, unmentioned features. Depth-2 pragmatic listeners integrate this feature dilution penalty into reference resolution while unprompted expectations remain governed by visual salience. This mechanism disagrees most sharply with the current best model on cross-cutting displays where matching candidates differ in extraneous feature count (such as a two-feature object versus a three-feature object sharing the uttered word), predicting a robust preference for the simpler candidate rather than dividing choices evenly.
