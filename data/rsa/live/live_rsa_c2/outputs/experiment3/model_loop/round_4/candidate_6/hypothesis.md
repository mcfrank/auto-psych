We refine competition_distractor_endpoint_l2 by incorporating convex feature salience from convex_feature_salience_l2 into the shared visual referent prior. In visual reference games, human perceptual attention does not scale linearly with visual feature count; under Feature Integration Theory, multiple visual features combine superlinearly to produce accelerating visual conspicuity, establishing the maximal exemplar as the dominant figure in the visual scene while leaving intermediate objects unremarkable. Incorporating this convex feature scaling into the prior directly rectifies the model's severe underprediction of full objects over empty baselines on mumble trials (mumble_full_over_empty_rate) and reduces over-selection of strictly intermediate-complexity objects on both unprompted mumble trials (mumble_intermediate_rate) and matching word trials (word_intermediate_match_rate).

Differences from competition_distractor_endpoint_l2:
- Recursion depth: Unchanged; choice_probs calls L2.
- Parameters added: gamma_features (prior: dist.LogNormal(0.5, 0.5)).
- Parameters removed: None.
- Shared visual referent prior / feature complexity: Replaces linear visual feature count (params["w_features"] * ctx.feature_count) with convex feature salience from convex_feature_salience_l2 (params["w_features"] * convex_fc, where rel_fc = ctx.feature_count / max_fc, safe_rel_fc = jnp.where(rel_fc > 0, rel_fc, 1.0), and convex_fc = jnp.where(rel_fc > 0, safe_rel_fc ** params["gamma_features"], 0.0)).
- All other terms: Perceptual distractor interference in speaker utility (w_threat), lexical competition in speaker communicative precision (w_competition), contextual endpoint salience (w_endpoint * is_endpoint), perceptual feature-binding noise on non-matching distractors (w_binding), capacity-limited inferential updating (kappa) at L1 and L2, contextual feature prevalence accessibility (w_prevalence), referential equivalence class size redundancy discounting (w_redundancy via compute_equivalence_class) on speaker alternatives in S1 and S2, literal truth-conditional semantics at L0, baseline prior components (w_singleton, w_distinct, w_empty, w_color), depth-2 RSA recursion, and salience-captured attentional lapse mixing remain identical to competition_distractor_endpoint_l2.
