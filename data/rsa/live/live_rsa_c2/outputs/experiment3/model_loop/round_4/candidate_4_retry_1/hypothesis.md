We refine competition_endpoint_binding_lapse_l2 by incorporating convex visual feature salience from convex_feature_salience_l2 into the shared visual referent prior. In visual reference games, human perceptual attention does not scale linearly with visual feature complexity; under Feature Integration Theory and psychophysical conspicuity, visual features combine superlinearly, establishing the maximal visual exemplar as the dominant figure in the scene while leaving intermediate items unremarkable. Pragmatic listeners and speakers incorporate this convex feature salience into communicative inference alongside lexical competition and endpoint salience, directly resolving the incumbent model's severe underprediction of full objects over empty baselines on mumble trials (mumble_full_over_empty_rate) and reducing over-selection of strictly intermediate-complexity objects on both word trials (word_intermediate_match_rate) and unprompted mumble trials (mumble_intermediate_rate).

Differences from competition_endpoint_binding_lapse_l2:
- Recursion depth: Unchanged; choice_probs calls L2.
- Parameters added: gamma_features (prior: dist.LogNormal(0.5, 0.5)).
- Parameters removed: None.
- Shared visual referent prior / feature complexity: Replaces linear visual feature count (params["w_features"] * ctx.feature_count) with convex feature salience from convex_feature_salience_l2 (params["w_features"] * convex_fc, where rel_fc = ctx.feature_count / max_fc, safe_rel_fc = jnp.where(rel_fc > 0, rel_fc, 1.0), and convex_fc = jnp.where(rel_fc > 0, safe_rel_fc ** params["gamma_features"], 0.0)).
- All other terms: Contextual end-point salience (w_endpoint) in the shared visual referent prior (alongside w_singleton, w_distinct, w_empty, and w_color), lexical competition in speaker utterance production (w_competition), capacity-limited inferential updating (kappa) at L1 and L2, contextual feature prevalence accessibility (w_prevalence) and referential equivalence class size redundancy discounting (w_redundancy via compute_equivalence_class) on speaker alternatives in S1 and S2, literal truth-conditional semantics at L0, depth-2 RSA recursion, perceptual feature-binding noise on non-matching distractors (w_binding), and salience-captured attentional lapse mixing remain identical to competition_endpoint_binding_lapse_l2.
