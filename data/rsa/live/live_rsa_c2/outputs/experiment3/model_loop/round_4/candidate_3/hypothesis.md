When resolving referring expressions in visual reference games, listeners operate under selective dimensional attention (Garner filtering): on unprompted trials, perceptual attention is distributed holistically across all visual dimensions according to bottom-up feature conspicuity, whereas hearing an informative referring expression triggers selective attentional narrowing to the mentioned attribute, attenuating the perceptual salience of extraneous, unmentioned visual features. Pragmatic listeners invert informative speakers under this dimension-filtered prior, which directly resolves the incumbent model's underprediction of simpler matching candidates in cross-cutting displays (non_nested_fewer_features_rate) and overprediction of intermediate matching objects (word_intermediate_match_rate) while preserving robust exemplar salience on unprompted trials (mumble_full_over_empty_rate). This mechanism disagrees most sharply with the current best model on cross-cutting displays where matching candidates vary in extraneous feature complexity (such as a two-feature object versus a three-feature object sharing the uttered word), predicting a robust preference for the simpler candidate rather than dividing choices evenly.
