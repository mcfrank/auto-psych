Listeners interpret referential expressions by inferring the speaker's communicative goal, modeling the speaker as aiming to inform them about an aspect of the object rather than its unique referential identity. When describing an object, speakers select among its true features by balancing lexical accessibility with contextual distinctiveness, and name the chosen aspect. A pragmatic listener inverts this goal-directed speaker, reasoning that hearing a shared feature provides stronger evidence for a minimally described object whose only communicative aspect was named than for an object with multiple features whose communicative focus was divided.
