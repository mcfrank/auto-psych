Listeners interpret utterances literally rather than pragmatically: they select among referents of which the heard word is true based strictly on prior contextual salience, without simulating alternative words a speaker could have chosen. On a display with a one-feature object and a two-feature object that both possess the named feature, this mechanism predicts that listeners will favor the two-feature object because its greater feature count makes it more salient a priori, directly reversing the pragmatic model's prediction that the one-feature object is favored because a speaker meaning the two-feature object would have named its alternative feature.
