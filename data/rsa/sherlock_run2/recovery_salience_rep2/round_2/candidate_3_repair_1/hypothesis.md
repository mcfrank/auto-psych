Listeners evaluate referential expressions through graded semantic truth values, where a word's degree of truth is inversely modulated by the referent's visual complexity. Because an object with multiple features is only partially characterized by any single feature label, literal listeners assign lower semantic applicability to complex referents than to simple referents that possess only the named feature. Pragmatic listeners invert a communicative speaker simulating this graded-truth literal listener, and on uninformative baseline trials, default to the same cognitive simplicity preference.
