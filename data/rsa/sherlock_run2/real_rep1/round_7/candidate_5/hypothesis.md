We refine depth-2 RSA with singleton and distinctiveness salience, visual feature complexity, visual color contrast, and literal L0 (rsa_l2_singleton_distinct_feat_color_l0) by incorporating the grammatical exhaustivity component from rsa_l2_singleton_distinct_features_exh into the depth-2 pragmatic listener. When interpreting referring expressions or choosing referents a priori, speakers and listeners reason recursively at depth 2 under an object prior combining discrete visual singleton salience, continuous contextual distinctiveness, visual feature complexity, and visual color contrast favoring fully colored objects over desaturated grayscale distractors, while the simulated foundational literal listener L0 interprets words purely according to conventional truth-conditional semantics without perceptual bias, and the depth-2 pragmatic listener additionally applies an exhaustification penalty to referents possessing superfluous unmentioned features in the communicative context. This fits better by maintaining uncompounded literal semantics, visual feature complexity, and color contrast while penalizing candidate referents that carry extraneous unmentioned features that informative speakers avoid, correcting the incumbent's deficit on displays with redundant features where empirical listeners disfavor overspecified distractors. Differences from rsa_l2_singleton_distinct_feat_color_l0: recursion depth remains depth 2 (choice_probs calls L2); parameter lambda_exh (LogNormal(0.0, 1.0)) is added; no parameters are removed; in L2, the listener adds listener: knows(u), receives ctx.feature_count, and chooses referents weighted by Pr[speaker.r == r] * exp(-lambda_exh * (vec(feature_count, r) - at(lex, u, r))) rather than Pr[speaker.r == r]; and choice_probs passes lambda_exh and ctx.feature_count to L2.
