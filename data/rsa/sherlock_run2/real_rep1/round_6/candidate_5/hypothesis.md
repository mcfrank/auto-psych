We refine depth-2 RSA with singleton and distinctiveness salience, visual feature complexity, and literal L0 (rsa_l2_singleton_distinct_features_l0) by incorporating the visual color contrast component from rsa_l2_shared_color_prior into the shared perceptual salience prior across communicative reasoning levels. When interpreting referring expressions or choosing referents a priori, speakers and listeners reason recursively at depth 2 under an object prior combining discrete visual singleton salience, continuous contextual distinctiveness, visual feature complexity, and visual color contrast favoring fully colored objects over desaturated grayscale distractors, while the simulated foundational literal listener L0 interprets words purely according to conventional truth-conditional semantics without perceptual bias. This fits better by maintaining uncompounded literal semantics and recursive pragmatic competence while capturing human bottom-up visual attention biases toward chromatic colored objects over grayscale distractors that the incumbent treats with identical baseline prior weight whenever they share the same feature density. Differences from rsa_l2_singleton_distinct_features_l0: recursion depth remains depth 2 (choice_probs calls L2); parameter w_color (Normal(0.0, 1.0)) is added; no parameters are removed; and the shared softmax salience prior computed in choice_probs adds w_color times each object's visual color contrast (1.0 - ctx.grayscale) to the existing singleton, distinctiveness, and feature count terms.
