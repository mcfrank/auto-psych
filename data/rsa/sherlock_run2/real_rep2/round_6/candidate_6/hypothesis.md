Listeners interpret referring expressions through depth-2 pragmatic reasoning that jointly accounts for perceptual isolation, graded semantic applicability, and contextual feature surprisal. When resolving an ambiguous word, listeners invert a speaker who evaluates graded semantic truth values while expecting speakers to favor candidate referents that pop out via nearest-neighbor contrast and possess high cumulative information content from rare or unexpected visual features in the display. On uninformative prior trials without an informative word, listeners' expectations directly follow this integrated prior of perceptual isolation and feature surprisal.

This model refines `isolated_graded_l2` by incorporating contextual feature surprisal from `feature_surprisal_l2` into the shared referent prior. While perceptual isolation captures visual pop-out on twin displays and graded semantics discounts cluttered objects with competing visual attributes, people also expect communication to focus on entities with high contextual information content characterized by rare visual features that distinguish them from display-wide baselines.

Differences from `isolated_graded_l2`:
- Recursion depth: Remains 2 (`choice_probs` calls `L2`).
- Parameters added: `w_surprisal` with prior `dist.Normal(0.0, 1.0)`. Parameters removed: None (retains `alpha`, `w_distinct`, `gamma`, and `lapse`).
- Other terms: Computes cumulative contextual feature surprisal for each object (`surp = object_feature_surprisal(ctx.lex, ctx.is_sink)`). In `choice_probs`, the object prior integrates feature surprisal alongside perceptual isolation: `prior = softmax_prior(params["w_distinct"] * dist_vec + params["w_surprisal"] * surp)`. All other components (`L0`, `L1`, `L2`, `object_isolation`, `compute_graded_lex`, and the lapse mixture) remain identical.
