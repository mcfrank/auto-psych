People interpret referring expressions using graded semantic truth values determined by contextual cue validity: a feature word's semantic applicability to an object diminishes when that object possesses alternative visual attributes that are far more distinctive and specific within the display context. When hearing an ambiguous word, listeners invert a speaker who communicates using these diagnostic truth values through recursive pragmatic reasoning, treating objects with unique identifying features as poor semantic matches for overextended descriptions. On uninformative prior trials, listeners guess uniformly among available objects.
