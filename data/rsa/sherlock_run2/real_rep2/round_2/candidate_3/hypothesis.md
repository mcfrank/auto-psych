People interpret referring expressions using graded truth values rather than binary Boolean semantics: a feature word's semantic applicability to an object diminishes with the number of additional visual features that object possesses. When hearing a word, listeners and speakers treat an object defined solely by that feature as a more prototypical, high-truth match than an object where the feature is diluted by competing visual attributes. Pragmatic listeners invert an informative speaker who evaluates candidate utterances using these graded semantic truth values.
