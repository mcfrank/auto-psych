Listeners interpret referring expressions through depth-3 pragmatic reasoning that jointly accounts for perceptual isolation, contextual feature surprisal, graded semantic applicability, and utterance extension costs. When resolving an ambiguous referring expression, listeners invert a speaker who anticipates a depth-2 pragmatic listener's interpretation, expecting speakers to refer preferentially to objects that exhibit nearest-neighbor visual contrast and contain rare or unexpected visual features in the display, while penalizing feature dilution and overextended descriptions. On uninformative prior trials without an informative word, listeners' expectations directly follow this integrated prior of perceptual isolation and feature surprisal.

This model refines `isolated_graded_costly_l3` by incorporating contextual feature surprisal from `surprisal_isolated_graded_l2` into the shared referent prior. While depth-3 reasoning, nearest-neighbor isolation, and utterance extension costs successfully resolve complex scalar implicatures and singleton pop-out, listeners also expect communication to focus on entities with high contextual information content characterized by rare visual features that distinguish them from display-wide baselines.

Differences from `isolated_graded_costly_l3`:
- Recursion depth: Remains 3 (`choice_probs` calls `L3`).
- Parameters added: `w_surprisal` with prior `dist.Normal(0.0, 1.0)`. Parameters removed: None (retains `alpha`, `w_distinct`, `gamma`, `cost_weight`, and `lapse`).
- Other terms: Computes cumulative contextual feature surprisal for each object (`surp = object_feature_surprisal(ctx.lex, ctx.is_sink)`). In `choice_probs`, the object prior integrates feature surprisal alongside perceptual isolation: `prior = softmax_prior(params["w_distinct"] * dist_vec + params["w_surprisal"] * surp)`. All other components (`L0`, `L1`, `L2`, `L3`, `object_isolation`, `compute_graded_lex`, utterance extension costs, and the lapse mixture) remain identical.
