Listeners interpret referring expressions under limited visual attention across display features: in a visual scene, attention is captured by contextually distinctive features that pop out against the display, so that common features shared broadly across competitors are attentionally discounted. When evaluating literal semantics, listeners weight an object's compatibility by the heard feature's share of that object's contextual visual salience, expecting speakers to refer using an object's most distinctive properties rather than ubiquitous descriptors. Communicative speakers choose expressions anticipating this contrastive feature-attribution inference, while spontaneous visual attention on uninformative displays defaults to contextually unique singletons.
