Listeners interpret referring expressions through description exhaustivity, assuming that cooperative speakers use single words to exhaustively describe minimal referents and applying a discrete non-exhaustivity penalty to any candidate referent possessing unmentioned features regardless of how many additional features it has. Communicative speakers choose expressions by anticipating this exhaustivity-sensitive listener, while spontaneous visual attention on uninformative displays defaults to contextually unique singletons. On multi-level scalar hierarchy displays containing minimal, intermediate, and maximal candidates, this mechanism predicts that listeners reject intermediate competitors almost as completely as maximal competitors because both violate description exhaustivity, disagreeing sharply with feature-uncertainty models that scale smoothly with feature count and over-predict intermediate choices.
