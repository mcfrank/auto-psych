Listeners interpret referring expressions with strictly bounded reasoning depth (depth 1) by inverting an informative communicative speaker, but evaluate semantic applicability as graded truth that diminishes with each additional competing visual feature. Refining bounded_depth_listener by incorporating graded semantic applicability from isolated_graded_costly_l3 into the literal semantics: candidate referents with additional unmentioned visual features possess lower baseline applicability, enabling listeners to strongly favor minimal referents when words are universally shared while maintaining visual singleton salience on uninformative displays. Differences from bounded_depth_listener: recursion depth remains depth 1 (listener calls L1); parameter gamma is added with prior dist.Normal(0.0, 1.0); no parameters are removed (retaining alpha and w_singleton); literal lexicon applicability is scaled by exp(-gamma * (feature_count - 1)) for real utterances; and the listener passes this graded lexicon into L1 on informative trials.
