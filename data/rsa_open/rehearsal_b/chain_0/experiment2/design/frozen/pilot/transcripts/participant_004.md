## Screen

Welcome. Welcome! In this short study, you will play a communication game where a speaker describes one of the objects on the screen.
It takes about 3.0 minutes.

Instructions:
On each turn, you and the speaker see the same row of objects, and one object is highlighted with an orange frame. The speaker has one target object in mind and says a single word that names a part on their target object. Your job is to rate how likely it is that the highlighted object is the speaker's target on a scale from 1 (Definitely not) to 7 (Definitely). If the highlighted object does not have the named part, it cannot be the target (rate it 1). If the highlighted object is the only object that has the named part, it is definitely the target (rate it 7). If more than one object has the named part, use the 1 to 7 scale to show how likely the highlighted object is to be the target. On some turns, the speaker's word was cut off; on those turns, rate how likely it is that the speaker is talking about the highlighted object.

What are you rating on each turn?
1) How likely it is that the highlighted object (in the orange frame) is the speaker's target, from 1 to 7
2) How many total parts all the objects have combined
3) Which word the speaker should have said instead
Reply ANSWER: <the option's number>.
