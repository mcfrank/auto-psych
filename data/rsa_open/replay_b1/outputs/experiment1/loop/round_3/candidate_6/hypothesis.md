We refine contextual_contrast_distinct_listener by incorporating visual empty-object baseline salience into the perceptual referent prior alongside discrete singleton pop-out and continuous contextual distinctiveness. Speakers choose referring expressions to maximize contextual contrast against visually similar competitors, and listeners interpret utterances by inverting this contrastive speaker, while expecting unadorned baseline objects lacking any features to be visually prominent candidates on uninformative displays before any message is heard. Differences from contextual_contrast_distinct_listener: recursion depth is unchanged (calls L_contrast); parameter w_empty is added with prior Normal(0.0, 1.0); the prior logit adds w_empty for objects lacking all display features (where ctx.feature_count is zero); no parameters or likelihood terms are removed.
